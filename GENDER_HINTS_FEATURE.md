# Динамические подсказки в зависимости от пола

## Что реализовано

Подсказки (hints) в полях ввода теперь автоматически меняются в зависимости от выбранного пола (мужской/женский).

## Изменения в коде

### Добавлены методы получения подсказок

В `custom_preset_creation_screen.dart` добавлены 4 метода:

#### 1. _getLocationHint()
**Женский:** "Уютное кафе в Париже, цветущий сад, берег океана"  
**Мужской:** "Крыша небоскрёба, горная вершина, мастерская"

#### 2. _getStyleHint()
**Женский:** "Вечернее платье, лёгкий летний сарафан, элегантный костюм"  
**Мужской:** "Деловой костюм-тройка, casual кожаная куртка, спортивный стиль"

#### 3. _getMoodHint()
**Женский:** "Романтичное, игривое и весёлое, уверенное и сильное"  
**Мужской:** "Брутальное и мужественное, задумчивое, энергичное и спортивное"

#### 4. _getDetailsHint()
**Женский:** "Букет пионов, изящные украшения, развевающиеся волосы"  
**Мужской:** "Стильные часы, борода с усами, кожаный портфель"

## Логика работы

### Автоматическое обновление

При переключении пола:
1. Пользователь нажимает на чип "Мужской" или "Женский"
2. Вызывается `setState(() => _selectedGender = _Gender.xxx)`
3. UI перестраивается
4. Методы `_getXxxHint()` возвращают новые подсказки
5. Поля отображают обновлённые подсказки

### Код до изменений

```dart
_buildInputField(
  controller: _styleController,
  label: 'Образ',
  hint: 'Элегантное платье, спортивный стиль', // ← статичная подсказка
  icon: Icons.style_outlined,
  maxLines: 3,
  theme: theme,
  colors: colors,
),
```

### Код после изменений

```dart
_buildInputField(
  controller: _styleController,
  label: 'Образ',
  hint: _getStyleHint(), // ← динамическая подсказка
  icon: Icons.style_outlined,
  maxLines: 3,
  theme: theme,
  colors: colors,
),
```

## Философия подсказок

### Принципы подбора примеров

1. **Релевантность полу**
   - Женские: элегантность, романтика, изящность
   - Мужские: брутальность, сила, стиль

2. **Разнообразие стилей**
   - От делового до casual
   - От романтичного до спортивного
   - От классики до современности

3. **Конкретность**
   - Не просто "платье", а "вечернее платье"
   - Не просто "костюм", а "деловой костюм-тройка"
   - Не просто "настроение", а "брутальное и мужественное"

4. **Визуальность**
   - Примеры помогают представить финальный результат
   - Легко понять что имеется в виду
   - Вдохновляют на креативность

## Расширение функциональности

### Если нужно добавить больше вариантов

Можно расширить методы рандомизацией:

```dart
String _getStyleHint() {
  if (_selectedGender == _Gender.female) {
    final variants = [
      'Вечернее платье, лёгкий летний сарафан, элегантный костюм',
      'Свадебное платье, коктейльное платье, деловой костюм',
      'Богемное платье макси, джинсы с блузкой, спортивный костюм',
    ];
    return variants[Random().nextInt(variants.length)];
  } else {
    final variants = [
      'Деловой костюм-тройка, casual кожаная куртка, спортивный стиль',
      'Смокинг, джинсы с рубашкой, байкерская куртка',
      'Классический костюм, поло с брюками, тренировочный костюм',
    ];
    return variants[Random().nextInt(variants.length)];
  }
}
```

### Добавление новых полей

При добавлении новых полей:
1. Создайте метод `_getXxxHint()`
2. Добавьте проверку `_selectedGender`
3. Верните релевантные примеры для каждого пола
4. Используйте метод в `_buildInputField(hint: _getXxxHint())`

## Преимущества

✅ **Понятность** - сразу ясно что вводить  
✅ **Автоматичность** - подсказки меняются моментально при переключении пола  

## Тестирование

1. Откройте экран "Создать свою фотосессию"
2. Выберите "Женский" пол
   - Проверьте подсказки: платье, украшения, романтичное
3. Переключите на "Мужской" пол
   - Подсказки изменятся: костюм, часы, брутальное
4. Убедитесь что подсказки обновились во всех полях

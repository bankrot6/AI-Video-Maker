# ✨ Эффект печатной машинки с глитчем

## 🎯 Что реализовано

Для заголовков онбоардинга добавлены два эффекта:

### 1. Эффект печатной машинки 
Текст появляется побуквенно, как в ChatGPT, создавая эффект живого набора текста.

### 2. Футуристический глитч-эффект
Во время печати текста случайным образом появляются визуальные "сбои системы":
- **RGB Split** (хроматическая аберрация) - разделение текста на красный и голубой каналы
- **Случайные символы** - появляются "мусорные" символы, как при сбое в системе
- **Мерцание** - текст слегка мигает во время глитча
- **Цветовые артефакты** - зеленые "следы" добавляют эффект матрицы

## 🎨 Визуальные характеристики

- **Скорость печати**: 50 миллисекунд на символ
- **Длительность глитча**: 80 миллисекунд
- **Вероятность глитча**: 30% при печати каждого символа
- **Сохранен оригинальный стиль**: белая обводка + черный текст с тенью

## 🚀 Как это работает

1. При загрузке страницы онбоардинга заголовок начинает "печататься"
2. Каждая буква появляется с небольшой задержкой
3. Случайным образом срабатывает глитч-эффект:
   - Добавляются случайные символы
   - Текст разделяется на цветные каналы
   - Появляются визуальные артефакты
4. **После завершения печати появляются кнопки с ответами** ⭐
5. Кнопки появляются с анимацией последовательно (50мс задержка между ними)

## 🔧 Настройка

Если нужно изменить параметры эффекта, отредактируйте файл `onboarding_screen.dart`:

```dart
TypewriterGlitchText(
  key: ValueKey(titleKey),
  text: context.tr(titleKey),
  style: const TextStyle(...),
  typingSpeed: const Duration(milliseconds: 50),    // ← Скорость печати
  glitchDuration: const Duration(milliseconds: 80), // ← Длительность глитча
)
```

### Параметры для настройки:

- `typingSpeed` - скорость появления символов (меньше = быстрее)
- `glitchDuration` - как долго длится эффект глитча
- В файле `typewriter_glitch_text.dart` можно изменить:
  - Вероятность глитча (строка 93: `_random.nextDouble() < 0.3`)
  - Набор глитч-символов (строка 32)
  - Интенсивность RGB split (строки 160, 186)

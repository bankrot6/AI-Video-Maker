# Улучшения поиска видео VK для упражнений

## Дата: 13 октября 2025

## Обзор изменений

Выполнен рефакторинг системы поиска видео для упражнений:
- **Улучшена** система поиска видео в VK Video
- **Добавлены** множественные поисковые запросы для лучших результатов
- **Реализован** реальный веб-поиск вместо статической базы данных

## Проблемы, которые были решены

### 1. Видео не находились
**Проблема:** Старая реализация использовала статическую базу данных с фиксированными ID видео, что приводило к тому, что большинство упражнений не находили видео.

**Решение:** Реализован реальный веб-поиск через публичный интерфейс VK Video.

### 2. Точное совпадение названий
**Проблема:** Требовалось точное совпадение названия упражнения с записями в базе данных.

**Решение:** Добавлены множественные варианты поисковых запросов с автоматическим добавлением фраз "техника выполнения", "как правильно делать".


## Детали реализации

### VK Video Search Service

Новый сервис использует следующий подход:

#### 1. Множественные поисковые запросы
```dart
List<String> _generateSearchQueries(String exerciseName) {
  final queries = <String>[];
  
  // 1. Техника выполнения (самый релевантный запрос)
  queries.add('$exerciseName техника выполнения');
  
  // 2. Как правильно делать
  queries.add('как правильно делать $exerciseName');
  
  // 3. Упражнение + техника
  queries.add('$exerciseName упражнение техника');
  
  // 4. Просто название упражнения
  queries.add(exerciseName);
  
  return queries;
}
```

Запросы выполняются последовательно, пока не найдется подходящее видео.

#### 2. Веб-скрейпинг VK
- Использует публичный поиск VK без необходимости токена
- Извлекает ID видео из HTML страницы поиска
- Берет первое найденное видео (обычно самое популярное)
- Опционально извлекает метаданные (название, просмотры)

#### 3. Улучшенные HTTP заголовки
```dart
headers: {
  'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
  'Accept': 'text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8',
  'Accept-Language': 'ru-RU,ru;q=0.9,en-US;q=0.8,en;q=0.7',
  'Accept-Encoding': 'gzip, deflate, br',
  'Connection': 'keep-alive',
}
```

Эмулирует реальный браузер для лучших результатов.

## Преимущества нового подхода

### 1. Больше находит видео
- Множественные варианты запросов увеличивают шансы найти видео
- Не зависит от статической базы данных
- Находит актуальные и популярные видео

### 2. Лучшая релевантность
- Запросы с фразами "техника выполнения" находят более подходящий контент
- Автоматический выбор самых популярных видео
- VK имеет большую базу фитнес-контента на русском языке

### 3. Простота поддержки
- Нет необходимости поддерживать статическую базу видео
- Единый источник видео (VK)
- Меньше кода, меньше потенциальных ошибок

### 4. Производительность
- Нативный VK Video плеер обеспечивает отличную производительность
- Оптимизированные HTTP запросы с задержками

1. **Проверьте разные упражнения:**

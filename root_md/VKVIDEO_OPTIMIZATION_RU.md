# Оптимизация поиска видео VKVideo

## ✅ Реализовано

### 1. Поиск ТОЛЬКО по vkvideo.ru

**Было:** Запросы по разным сайтам (vk.com, vkvideo.ru) и без site:
```dart
final queries = <String>[
  '$exerciseName техника выполнения',
  'как правильно делать $exerciseName',
  '$exerciseName упражнение техника',
  '$exerciseName техника выполнения site:vk.com/video',
  '$exerciseName техника выполнения site:vkvideo.ru',
];
```

**Стало:** Только целевые запросы по vkvideo.ru
```dart
final queries = <String>[
  '$exerciseName техника выполнения site:vkvideo.ru',
  '$exerciseName упражнение site:vkvideo.ru',
  'как делать $exerciseName site:vkvideo.ru',
];
```

**Преимущества:**
- ✅ Меньше мусора в результатах
- ✅ Только качественные видео с vkvideo.ru
- ✅ Быстрее (меньше запросов)
- ✅ Меньше вероятность капчи

### 2. Кэширование видео

**Реализовано:**
- Проверка кэша перед поиском
- Мгновенная загрузка из кэша при повторном открытии
- Сохранение топ-4 видео
- Кэш на 30 дней

**Логика:**
```dart
// 1) Проверяем кэш
final cachedVideos = await cacheService.getCachedVideos(exerciseName);

if (cachedVideos.isNotEmpty) {
  // Мгновенно загружаем из кэша
  debugPrint('💾 Загружено ${cachedVideos.length} видео из кэша');
  candidates = cachedVideos.map(...).toList();
} else {
  // Первый раз - ищем через Яндекс
  debugPrint('🔍 Кэш пуст, ищем через Яндекс');
  candidates = await aggregator.searchCandidates(exerciseName);
  // Сохраняем в кэш
  cacheService.cacheExerciseVideos(exerciseName, toStore);
}
```

### 3. Топ-4 видео

**Ограничение:**
```dart
// Берём только топ-4
results.take(4)

// В кэше храним тоже только 4
final limited = videos.take(4).toList();
```

### 4. Предзагрузка видео

**Последовательность:**
1. Пользователь открывает упражнение
2. **Мгновенно** загружаются видео из кэша (если есть)
3. Или ищутся через Яндекс и кэшируются
4. При следующем открытии - мгновенная загрузка из кэша

  }

### Срок жизни: 30 дней
```dart
static const Duration _cacheDuration = Duration(days: 30);
```

### Проверка актуальности:
```dart
if (cachedAt != null) {
  final age = DateTime.now().difference(
    DateTime.fromMillisecondsSinceEpoch(cachedAt)
  );
  if (age > _cacheDuration) {
    return null; // Кэш устарел
  }
}
```

# Финальное исправление дублирования упражнений

## Глубокий анализ проблемы 🔍

### Симптомы
На главной странице после онбоардинга дни 2 и 3 **сначала** отображались с дублированными упражнениями, **затем** заменялись на правильные данные.

### Корень проблемы

Проблема была в **конфликте двух систем генерации**, работающих одновременно:

```
ОНБОАРДИНГ (train_plan_screen.dart)
├─ Генерирует День 1 с UI
└─ Запускает фоновую генерацию дней 2-3
   └─ Использует _generateOneDayWithoutUI()
      └─ tryParseWorkoutFromText() (JSON парсинг) ❌
         └─ Возвращает промежуточный JSON с дублированием
            └─ Сохраняет ПЛОХИЕ данные
               └─ Инвалидирует UI → пользователь видит дубликаты!

↓ Пользователь переходит на главную ↓

ГЛАВНАЯ СТРАНИЦА (home_screen.dart)
└─ Запускает _ensureWeeklyWorkoutsAreComplete()
   └─ BackgroundWorkoutGenerationService
      └─ _generateDayWithStreaming()
         └─ _parseStreamingText() (текстовый парсинг) ✅
            └─ Проверка дубликатов по имени
               └─ Сохраняет ХОРОШИЕ данные
                  └─ Инвалидирует UI → пользователь видит правильные упражнения!
```

### Временная линия

```
t=0s:   Онбоардинг генерирует День 1 ✅
t=1s:   Онбоардинг запускает фоновую генерацию Дня 2
t=2s:   День 2 сохранён с дублированием ❌
t=3s:   UI обновлён → пользователь видит дубликаты
t=4s:   Онбоардинг генерирует День 3 с дублированием ❌
t=5s:   Пользователь переходит на главную
t=6s:   Главная запускает свою фоновую генерацию
t=7s:   День 2 перегенерирован правильно ✅
t=8s:   UI обновлён → дубликаты исчезли!
t=9s:   День 3 перегенерирован правильно ✅
t=10s:  UI обновлён → всё корректно
```

## Решение ✅

### 1. Исправлен метод в онбоардинге

**Файл:** `lib/features/onboarding/train_plan_screen.dart`

**Метод:** `_generateOneDayWithoutUI()`

#### Было (❌):
```dart
generator.streamWorkoutText(...).listen((chunk) {
  buffer.write(chunk);

  // Парсим промежуточные данные (без UI)
  final parsed = generator.tryParseWorkoutFromText(buffer.toString());
  if (parsed != null) {
    dayTitle = parsed.dayTitle;
    exercises.clear();
    exercises.addAll(parsed.exercises);  // ← Дублирование!
  }
}
```

**Проблема:** `tryParseWorkoutFromText()` возвращает промежуточный JSON, который может содержать одно и то же упражнение несколько раз.

#### Стало (✅):
```dart
generator.streamWorkoutText(...).listen((chunk) {
  buffer.write(chunk);

  // ИСПРАВЛЕНО: Парсим текстовый поток вместо JSON
  final text = buffer.toString();
  
  // Извлекаем заголовок
  final dayMatch = RegExp(r'DAY:\s*([^\n]+)').firstMatch(text);
  if (dayMatch != null) {
    dayTitle = dayMatch.group(1)?.trim();
  }

  // Извлекаем упражнения из текстового формата
  final exMatches = RegExp(r'EX:\s*([^\n]+)').allMatches(text);
  final List<ExerciseItem> parsedExercises = [];
  
  for (final match in exMatches) {
    final payload = match.group(1)?.trim();
    final parts = payload.split('|');
    if (parts.length >= 4) {
      parsedExercises.add(ExerciseItem(
        name: parts[0].trim(),
        sets: int.parse(parts[1].trim()),
        reps: int.parse(parts[2].trim()),
        weightKg: double.parse(parts[3].trim()),
      ));
    }
  }

  // Обновляем список БЕЗ дублирования
  for (final ex in parsedExercises) {
    final existingIndex = exercises.indexWhere((e) => e.name == ex.name);
    if (existingIndex != -1) {
      exercises[existingIndex] = ex;  // Обновляем существующее
    } else if (exercises.length < targetExercises) {
      exercises.add(ex);  // Добавляем новое
    }
  }
}
```

**Результат:** Теперь онбоардинг сохраняет правильные данные сразу, без дублирования!

### 2. Оптимизирована фоновая генерация на главной

**Файл:** `lib/features/home/home_screen.dart`

**Метод:** `_ensureWeeklyWorkoutsAreComplete()`

#### Изменения:

1. **Увеличена задержка** с 500ms до 2 секунд
   - Даёт онбоардингу время завершить генерацию
   - Предотвращает дублирование работы

2. **Добавлены метки FALLBACK**
   - Ясно показывает, что это резервная система
   - Запускается только если онбоардинг не успел

3. **Улучшенное логирование**
   - Показывает сколько дней уже есть
   - Показывает сколько нужно догрузить

```dart
// Даём больше времени онбоардингу завершить генерацию
await Future.delayed(const Duration(seconds: 2));

if (existingPlan.isComplete) {
  debugPrint('✅ ФОНОВАЯ ГЕНЕРАЦИЯ (FALLBACK): План уже полный (3/3)');
  return;
}

// FALLBACK: Онбоардинг не успел завершить генерацию
debugPrint('🔄 ФОНОВАЯ ГЕНЕРАЦИЯ (FALLBACK): Онбоардинг не завершил, догружаем дни 2-3');
```

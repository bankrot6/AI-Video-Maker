# AI Video Maker - Анализ Питательной Ценности Блюд

Это приложение на Flutter для анализа питательной ценности блюд с использованием возможностей компьютерного зрения и искусственного интеллекта.

## Функциональность

- Распознавание и анализ блюд через камеру или галерею
- Расчет питательной ценности (белки, жиры, углеводы, калории)
- Определение ингредиентов и их веса
- Интеграция с Google Cloud Vision и DeepSeek AI

## Требования

- Flutter SDK (последняя стабильная версия)
- Dart SDK (последняя стабильная версия)
- Android Studio / VS Code
- API ключи для:
  - DeepSeek AI
  - Google Cloud Vision (опционально)
  - Google Cloud Speech-to-Text (опционально для голосового ввода)

## Установка

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/yourusername/chatcoach.git
   cd chatcoach
   ```

2. Установите зависимости:
   ```
   flutter pub get
   ```

3. Создайте файл `.env` в корне проекта и добавьте API ключи:
   ```
   DEEPSEEK_API_KEY=ваш_ключ_deepseek
   GOOGLE_CLOUD_VISION_API_KEY=ваш_ключ_google_vision
   GOOGLE_SPEECH_API_KEY=ваш_ключ_google_speech
   OPENAI_API_KEY=ваш_ключ_openai
   ```

## Настройка API ключей

### DeepSeek AI
1. Зарегистрируйтесь на [DeepSeek AI](https://platform.deepseek.ai/)
2. Перейдите в раздел "API Keys" в настройках аккаунта
3. Создайте новый ключ и скопируйте его
4. Добавьте ключ в файл `.env`

### Google Cloud Vision (опционально)
1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Активируйте Vision API для проекта
3. Создайте учетные данные API и получите ключ
4. Добавьте ключ в файл `.env`

### Google Cloud Speech-to-Text (опционально)
1. Используйте тот же проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Активируйте Speech-to-Text API для проекта
3. Создайте учетные данные API и получите ключ
4. Добавьте ключ GOOGLE_SPEECH_API_KEY в файл `.env`

## Запуск

```
flutter run
```

## Режим тестирования

Если API ключи не настроены, приложение будет работать в тестовом режиме с использованием моков. В этом режиме данные генерируются локально и не требуют подключения к API.

## Архитектура

Проект использует архитектуру, основанную на принципах SOLID с следующими компонентами:

- **Модели**: Представление данных (NutritionInfo, Ingredient, DishType)
- **Сервисы**: Логика работы с API (DeepSeekService, VisionService)
- **Интеграторы**: Интеграция различных сервисов (VisionDeepSeekIntegrator)
- **Провайдеры**: Управление состоянием с Riverpod
- **UI**: Экраны и компоненты пользовательского интерфейса

## Уведомления и напоминания

Приложение поддерживает локальные уведомления для напоминаний о приемах пищи:

- **Напоминания о приемах пищи**: Настраиваемые уведомления о завтраке, обеде и ужине
- **Отображение на переднем плане**: Корректное отображение уведомлений, даже когда приложение активно
- **Экран отладки**: Встроенные инструменты для тестирования и отладки уведомлений

### Настройка уведомлений на iOS

Для корректной работы уведомлений на iOS, особенно при отображении на переднем плане, требуются специальные настройки. Подробная документация доступна в [docs/ios_foreground_notifications.md](docs/ios_foreground_notifications.md).

### Инструменты отладки

Приложение включает экран отладки уведомлений, который позволяет:

1. Отправлять тестовые уведомления
2. Проверять статус и разрешения уведомлений
3. Тестировать уведомления на переднем плане
4. Запрашивать разрешения на уведомления

# Руководство по тестированию интеграции RuStore

## Проблема

Пользователь загрузил приложение в RuStore, скачал его оттуда, но при нажатии на кнопку подписки получает сообщение от Google Play Market вместо RuStore.

## Диагностика проблемы

### 1. Проверка определения источника установки

1. Запустите приложение в debug режиме
2. Перейдите в Настройки → "Диагностика платежей"
3. Проверьте следующие параметры:
   - **Источник установки**: Должен быть "RuStore"
   - **Активный провайдер**: Должен быть "rustore"
   - **Локаль**: Проверьте код страны

### 2. Возможные причины проблемы

#### A. Неправильное определение источника установки
- **Симптом**: Источник установки показывает "Google Play Store" или "Неизвестный источник"
- **Причина**: Пакет `store_checker` не может корректно определить RuStore
- **Решение**: Проверить версию `store_checker` и убедиться в корректной установке из RuStore

#### B. Ошибка в логике выбора провайдера
- **Симптом**: Источник определяется как RuStore, но провайдер не "rustore"
- **Причина**: Ошибка в логике `paymentProviderTypeProvider`
- **Решение**: Проверить код в `lib/services/payment_providers.dart`

#### C. Проблема с fallback логикой
- **Симптом**: Приложение использует стандартные IAP вместо RuStore
- **Причина**: Ошибка инициализации RuStore приводит к fallback на Google Play
- **Решение**: Проверить логику в `paywall_screen.dart`

### 3. Тестирование с принудительной установкой провайдера

В диагностическом экране есть кнопки для принудительного тестирования:

1. **Тест RuStore** - принудительно устанавливает источник как RuStore
2. **Тест Google Play** - принудительно устанавливает источник как Google Play  
3. **Тест App Store** - принудительно устанавливает источник как App Store
4. **Сброс** - возвращает к реальному определению

После установки принудительного источника:
1. Перейдите на экран подписки (Paywall)
2. Попробуйте купить подписку
3. Проверьте логи в консоли

### 4. Проверка логов

Ищите в логах следующие сообщения:

```
🏪 STORE_DETECTION: Источник установки определен: AppStoreType.ruStore
🏪 PAYMENT_PROVIDER: Используем RuStore billing для пользователей RuStore
🟢 PAYWALL: Пользователь RuStore - используем RuStore биллинг
🛒 RUSTORE_BILLING: Создание платежа RuStore
```

### 5. Ожидаемое поведение для пользователей RuStore

1. **Определение источника**: `AppStoreType.ruStore`
2. **Выбор провайдера**: `PaymentProvider.rustore`
3. **Цены на экране**: Цены в рублях из `RuStoreBillingService`
4. **Процесс покупки**: Переход на веб-интерфейс RuStore (в текущей mock реализации)

## Код для анализа

### Основные файлы:

1. **`lib/services/app_store_detection_service.dart`** - Определение источника установки
2. **`lib/services/payment_providers.dart`** - Логика выбора провайдера
3. **`lib/features/subscription/paywall_screen.dart`** - UI и логика покупки
4. **`lib/services/rustore_billing_service.dart`** - Реализация RuStore биллинга

### Ключевые методы:

```dart
// Определение источника установки
AppStoreDetectionService().getInstallationSource()

// Выбор провайдера платежей  
ref.read(paymentProviderTypeProvider.future)

// Логика в paywall_screen.dart
switch (paymentProviderType) {
  case PaymentProvider.rustore:
    await _startRuStoreSubscription();
    break;
  // ...
}
```

## Возможные решения

### 1. Если источник определяется неправильно

Обновить пакет `store_checker` или добавить дополнительную логику определения:

```dart
// В app_store_detection_service.dart
// Добавить дополнительные проверки для RuStore
```

### 2. Если логика выбора провайдера неправильная

Проверить условия в `paymentProviderTypeProvider`:

```dart
switch (installationSource) {
  case AppStoreType.ruStore:
    return PaymentProvider.rustore; // Должно быть именно так
  // ...
}
```

### 3. Если RuStore биллинг не инициализируется

Проверить реализацию `RuStoreBillingService.initialize()` и обработку ошибок.

## Отладка в production

Для отладки в production версии можно:

1. Добавить логирование в `AppLogger`
2. Создать специальную версию с включенным debug режимом
3. Использовать аналитику для отслеживания источников установки

## 🔧 Что нужно настроить

### Обязательно: Google Maps API Key с Text-to-Speech

В файле `.env` используется тот же ключ что и для карт:

```env
GOOGLE_MAPS_API_KEY=ваш_настоящий_ключ_здесь
```

**Как включить Text-to-Speech для существующего ключа:**

1. Откройте [Google Cloud Console](https://console.cloud.google.com/)
2. Выберите тот же проект где настроен Google Maps
3. В меню найдите **APIs & Services** → **Library**
4. Найдите и включите **Cloud Text-to-Speech API**
5. Ваш существующий `GOOGLE_MAPS_API_KEY` теперь будет работать для озвучки
6. Подождите 2-3 минуты для применения изменений

## 📱 Как протестировать

1. **Убедитесь, что API ключ настроен** в `.env` файле
2. **Запустите приложение**: `flutter run`
3. **Перейдите на главный экран** с планами поездок
4. **Откройте любой план поездки**
5. **Нажмите на карточку места** в списке "Места"
6. **Должен открыться экран с деталями места**:
   - ✅ Загрузится изображение места
   - ✅ Появится информация: История, Факты, Практ. инфо, Рекомендации
   - ✅ Есть кнопка "Озвучить экскурсию"
7. **Нажмите кнопку озвучки**:
   - ✅ Кнопка изменится на "Остановить"
   - ✅ Начнётся воспроизведение текста голосом
   - ✅ При повторном нажатии озвучка остановится

## ⚠️ Возможные проблемы

### Проблема: "Ошибка озвучки"
**Решение**: Проверьте, что `GOOGLE_SPEECH_API_KEY` правильно настроен в `.env`

### Проблема: Нет изображения места
**Решение**: Проверьте `GOOGLE_CSE_API_KEY` и `GOOGLE_CSE_ID` в `.env`

### Проблема: Пустой текст или ошибка AI
**Решение**: Проверьте `DEEPSEEK_API_KEY` в `.env`

# Потоковое отображение - Краткая справка

## Что реализовано

Дни 2-3 теперь генерируются на главной странице с потоковым отображением упражнений (как на онбоардинге для дня 1).

## Было ❌

```
[Загрузка 20 секунд...]
↓
День 2: [Все 6 упражнений сразу]
День 3: [Все 6 упражнений сразу]
```

## Стало ✅

```
День 2: Заголовок
       ↓ Упражнение 1
       ↓ Упражнение 2
       ↓ Упражнение 3
       ↓ ...

День 3: Заголовок
       ↓ Упражнение 1
       ↓ ...
```

## Как работает

```
ОНБОАРДИНГ
└─ Генерирует ТОЛЬКО День 1 ✅
   └─ Остальные дни отложены на главную

↓

ГЛАВНАЯ СТРАНИЦА
└─ Обнаруживает неполный план
   └─ Запускает потоковую генерацию
      ├─ workoutDayStreamingProvider
      ├─ Колбеки: onTitle, onExercise
      └─ UI обновляется автоматически
```

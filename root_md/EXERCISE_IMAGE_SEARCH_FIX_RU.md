# Исправление поиска изображений упражнений

## Дата: 12 ноября 2025

## Проблемы

1. **Не работает поиск изображений через Google**: На странице информации об упражнении всегда отображается заполнитель вместо реального изображения из Google Search
2. **Неправильное выравнивание заполнителя**: Изображение-заполнитель (робот) отображается с центрированием, из-за чего голова обрезается

- ✅ Отслеживание размера загруженного файла
- ✅ Предупреждения о проблемах с API ключами

- ✅ Реальные изображения упражнений также выглядят лучше

## Диагностика проблем

### Если вы всегда видите заполнитель, проверьте логи:

1. **Запустите приложение** и откройте страницу упражнения
2. **Просмотрите логи** в консоли
3. **Ищите строки:**
   - `❌ GoogleImageSearchService: ⚠️ API ключи не настроены!` - проблема с .env
   - `❌ GoogleImageSearchService: ❌ API ключ не задан` - отсутствует GOOGLE_CSE_API_KEY
   - `❌ GoogleImageSearchService: ❌ ID поисковой системы не задан` - отсутствует GOOGLE_CSE_ID
   - `❌ Ошибка API [код]` - проблема с квотой или настройками Google CSE
   - `⚠️ Изображения не найдены` - поиск не вернул результатов

### Настройка Google Custom Search API

Если API ключи не настроены, следуйте инструкции в файле `README_GOOGLE_CSE.md`:

1. Создайте проект в Google Cloud Platform
2. Включите Custom Search API
3. Создайте API ключ
4. Создайте поисковую систему на https://programmablesearch.google.com/
5. Включите "Image search" в настройках
6. Добавьте ключи в `.env` файл:
   ```
   GOOGLE_CSE_API_KEY=ваш_api_ключ
   GOOGLE_CSE_ID=ваш_id_поисковой_системы
   ```
7. Перезапустите приложение

### Проверка квоты API

Google Custom Search API имеет ограничения:
- 100 бесплатных запросов в день
- После исчерпания: $5 за 1000 запросов
- Максимум 10,000 запросов в день

Если квота исчерпана, в логах будет ошибка с кодом 429 или подобным.

# 🚀 Обновление DeepSeek API до версии R1-0528

## 📋 Выполненные улучшения

### ✅ 1. Обновление конфигурации DeepSeek

**Файл:** `lib/services/nutrition_analysis/deepseek/deepseek_config.dart`

- **max_tokens**: 500 → 32,000 (по умолчанию), 64,000 (максимум)
  - Теперь включает thinking process модели R1-0528
  - Быстрый режим: 16,000 токенов
- **model**: 'deepseek-chat' → 'deepseek-reasoner' 
  - Обновлено для доступа к новым возможностям R1-0528
- **Добавлены новые параметры:**
  - `enableFunctionCalling` - поддержка вызова функций
  - `enableJsonOutput` - улучшенный JSON Output
  - `response_format: {'type': 'json_object'}` - принудительный JSON ответ

### ✅ 2. Улучшенные промпты для enhanced reasoning

**Файл:** `lib/features/ai_chat/services/deepseek_dietitian_service.dart`

- **Добавлен thinking block** в промпты для глубокого анализа
- **Расширена структура JSON ответа:**
  - `micronutrients_analysis` - анализ микронутриентов
  - `timing_analysis` - анализ времени приемов пищи
  - `progress_assessment` - оценка прогресса
  - `actionable_steps` - конкретные шаги для улучшения
- **Отключен fastMode** для использования полных возможностей reasoning
- **Улучшены требования** к анализу с акцентом на научную обоснованность

### ✅ 3. Function Calling инфраструктура

**Новый файл:** `lib/services/nutrition_analysis/deepseek/nutrition_function_tools.dart`

Реализованы функции для нутрициологии:
- `calculate_daily_nutrition_norms` - расчет персональных норм БЖУ и калорий
- `analyze_macro_balance` - анализ баланса макронутриентов
- `suggest_meal_timing` - оптимизация времени приемов пищи  
- `calculate_bmr` - расчет базального метаболизма

**Обновлен:** `lib/services/nutrition_analysis/deepseek/deepseek_client.dart`
- Добавлена поддержка параметра `tools` в `generateText()`
- Автоматическое определение и обработка function calls
- Улучшенная обработка ошибок для новых типов ответов

### ✅ 4. Улучшенная обработка ошибок

- **Обработка пустого контента** от модели
- **Обработка Function Calling ответов**
- **Более детальное логирование** работы с R1-0528
- **Валидация JSON ответов** с fallback механизмами

## 📚 Техническая документация

### Новые параметры API
```dart
// Конфигурация для R1-0528
DeepSeekConfig(
  model: 'deepseek-reasoner',
  maxTokens: 32000,  // Включает thinking process
  enableJsonOutput: true,
  enableFunctionCalling: false, // Готово к включению
)
```

### Пример использования Function Calling
```dart
final tools = NutritionFunctionTools.getNutritionAnalysisTools();
final response = await client.generateText(prompt, tools: tools);
```

### Новая структура JSON ответа диетолога
```json
{
  "analysis": {
    "overall_assessment": "...",
    "micronutrients_analysis": "...",
    "timing_analysis": "...",
    "progress_assessment": "..."
  },
  "actionable_steps": ["..."],
  "meal_plan_suggestions": {
    "snacks": "..."
  }
}
```

# 🎨 Визуализация: До и После

## 📱 Эффект iOS 26 - Размытие нижней части контента

### ❌ **ДО ИЗМЕНЕНИЙ**

```
┌─────────────────────────────┐
│                             │
│    📝 Контент               │
│                             │
│    Упражнение 1             │
│    Упражнение 2             │
│    Упражнение 3             │
│    Упражнение 4             │
│                             │
├─────────────────────────────┤  ⟵ Жесткая граница (Clip.hardEdge)
│    ❌ ОБРЕЗАНО              │
│    ❌ Контент скрыт         │
└─────────────────────────────┘
│  🧊 Навигационный бар        │
└─────────────────────────────┘
```

**Проблемы:**
- ❌ Контент резко обрезается
- ❌ Нет плавного перехода
- ❌ Неестественный вид
- ❌ Не соответствует iOS стандартам

---

### ✅ **ПОСЛЕ ИЗМЕНЕНИЙ**

```
┌─────────────────────────────┐
│                             │
│    📝 Контент               │
│                             │
│    Упражнение 1             │
│    Упражнение 2             │
│    Упражнение 3   ████      │  ⟵ 100% непрозрачность
│    Упражнение 4   ████      │
│    Упражнение 5   ███░      │  ⟵ 75% начало fade-out
│    Упражнение 6   ██░░      │  ⟵ 50% fade + blur
│    Упражнени      █░░░      │  ⟵ 25% + сильное blur
│                   ░░░░      │  ⟵ 0% + максимальное blur
└─────────────────────────────┘
│  🌊 Навигационный бар        │  ⟵ Liquid Glass эффект
└─────────────────────────────┘
```

**Преимущества:**
- ✅ Плавное затухание (fade-out)
- ✅ Градиентное размытие (blur)
- ✅ Естественный переход
- ✅ Точно как в iOS 26
- ✅ Премиальный вид

---

## 🔄 Технический подход

### До (старый подход)
```dart
Container(
  margin: EdgeInsets.only(bottom: 100),  // Жесткое обрезание
  clipBehavior: Clip.hardEdge,           // Резкая граница
  child: SingleChildScrollView(
    child: Content(),
  ),
)
```

**Результат:** Контент резко обрезается ✂️

---

### После (iOS 26 подход)
```dart
Stack(
  children: [
    // Слой 1: Контент с плавным затуханием
    BottomFadeMask(
      fadeHeight: 140.0,
      fadeStart: 0.75,  // Начало затухания с 75%
      child: SingleChildScrollView(
        padding: EdgeInsets.only(bottom: 140),
        child: Content(),
      ),
    ),
    
    // Слой 2: Размытие снизу
    BottomContentBlur(
      blurHeight: 140.0,
      blurIntensity: 15.0,  // sigma для ImageFilter.blur
      overlayColor: Colors.black,
    ),
  ],
)
```

**Результат:** Плавное размытие как в iOS 🌊

## 🎯 Ключевые параметры

| Параметр          | Значение  | Назначение                           |
|-------------------|-----------|--------------------------------------|
| `blurHeight`      | `140.0`   | Высота области размытия              |
| `blurIntensity`   | `15.0`    | Сила размытия (sigma)                |
| `fadeStart`       | `0.75`    | Начало затухания (75% от верха)      |
| `bottomPadding`   | `140`     | Отступ снизу в ScrollView            |
| `overlayColor`    | `black`   | Цвет оверлея для темных тем          |

## 📐 Математика градиента

### ShaderMask (BottomFadeMask)
```dart
LinearGradient(
  begin: Alignment.topCenter,      // Сверху вниз
  end: Alignment.bottomCenter,
  colors: [
    Colors.white,       // 100% непрозрачность
    Colors.white,       // 100% непрозрачность
    Colors.transparent, // 0% непрозрачность
  ],
  stops: [
    0.0,    // Верх: полностью видимо
    0.75,   // 75%: начало затухания
    1.0,    // Низ: полностью прозрачно
  ],
)
```

### BackdropFilter (BottomContentBlur)
```dart
ImageFilter.blur(
  sigmaX: 15.0,  // Горизонтальное размытие
  sigmaY: 15.0,  // Вертикальное размытие
)

+ LinearGradient (оверлей):
  colors: [
    Colors.transparent,              // 0% непрозрачность
    overlayColor.withOpacity(0.02),  // 2% непрозрачность
    overlayColor.withOpacity(0.05),  // 5% непрозрачность
  ]
```

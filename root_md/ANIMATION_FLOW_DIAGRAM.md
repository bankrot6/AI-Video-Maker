## Диаграмма состояний (State Machine)

```
┌─────────────┐
│   START     │
│  Page Load  │
└─────┬───────┘
      │
      ↓
┌─────────────────────────────────┐
│   STATE 1: TYPING                │
│   _isTypingComplete = false      │
│   Кнопки: opacity = 0 (скрыты)   │
└─────────┬───────────────────────┘
          │
          ↓ каждые 50ms
     ┌────────┐
     │ Символ │
     └────┬───┘
          │
          ↓ 30% вероятность
     ┌─────────┐
     │ ГЛИТЧ!  │  (80ms)
     │ RGB+мерц│
     └────┬────┘
          │
          ↓ текст закончился
┌──────────────────────────────────┐
│   STATE 2: TYPING COMPLETE       │
│   onTypingComplete() вызван      │
│   _isTypingComplete = true       │
└────────┬─────────────────────────┘
         │
         ↓
┌──────────────────────────────────┐
│   STATE 3: BUTTONS ANIMATING     │
│   ScaleTransition активен        │
│   Кнопки появляются (350ms)      │
└────────┬─────────────────────────┘
         │
         ↓
┌──────────────────────────────────┐
│   STATE 4: INTERACTIVE           │
│   Кнопки полностью видны         │
│   Ожидание выбора пользователя   │
└────────┬─────────────────────────┘
         │
         ↓ пользователь выбрал
┌──────────────────────────────────┐
│   TRANSITION TO NEXT PAGE        │
│   _resetButtonAnimation()        │
│   _isTypingComplete = false      │
└────────┬─────────────────────────┘
         │
         ↓
    [Повтор для следующей страницы]
```

## Визуализация эффектов

### RGB Split эффект:
```
Нормально:  Какой ваш пол?

Во время глитча:
  Какой ваш пол?     ← Красный канал (смещен влево -2px)
    Какой ваш пол?   ← Основной текст (белый контур)
      Какой ваш пол? ← Синий канал (смещен вправо +2px)
         └→ Результат: хроматическая аберрация
```

### Мерцание:
```
t=0ms:   opacity: 1.0  █████████ (яркий)
t=50ms:  opacity: 0.5  ▓▓▓▓▓▓▓▓▓ (средний)
t=100ms: opacity: 0.3  ░░░░░░░░░ (тусклый)
t=80ms:  opacity: 1.0  █████████ (яркий снова)
```

### Зеленые артефакты:
```
           Какой ваш пол?      ← Основной текст
             Какой ваш пол?    ← Зеленый след (смещен случайно)
                               ↑ opacity: 0.4, случайное смещение
```

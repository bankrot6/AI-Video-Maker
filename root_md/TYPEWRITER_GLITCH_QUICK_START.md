# 🚀 Быстрый старт: Эффект печатной машинки с глитчем

## Что сделано?

На страницах онбоардинга теперь заголовки имеют два эффекта:

### 1️⃣ Эффект печатной машинки ⌨️
```
П... Пр... Прив... Привет!
```
Текст появляется побуквенно, как будто его печатают в реальном времени.

### 2️⃣ Глитч-эффект 💥
Во время печати случайно появляются:
- ❌ Цветные смещения (красный влево, синий вправо)
- 🔤 Случайные символы ("мусор" в системе)
- ⚡ Мерцание текста
- 🟢 Зеленые "следы" (как в Матрице)

## Как это выглядит?

**До:**
```
Какой ваш пол?
[Мужской] [Женский]  ← кнопки сразу видны
```

**После:**
```
К... Ка... Каќ@й... [ГЛИТЧ!] ...ваш п... пол?
     ^             ^
     |             |
Печатается    RGB Split + мерцание + артефакты

↓ После завершения печати ↓

Какой ваш пол?
[Мужской] [Женский]  ← кнопки появляются с анимацией!
```

## Запуск

Просто откройте приложение и пройдите онбоардинг:

```bash
flutter run
```

Эффект запустится автоматически при отображении каждого заголовка!

## Настройка скорости

В файле `onboarding_screen.dart` (строки 113-114):

```dart
typingSpeed: const Duration(milliseconds: 50),    // ← быстрее = меньше
glitchDuration: const Duration(milliseconds: 80), // ← короче = меньше
```

**Хотите быстрее?** Уменьшите значения:
```dart
typingSpeed: const Duration(milliseconds: 30),    // Очень быстро!
glitchDuration: const Duration(milliseconds: 50), // Быстрый глитч
```

**Хотите медленнее?** Увеличьте значения:
```dart
typingSpeed: const Duration(milliseconds: 100),   // Медленно
glitchDuration: const Duration(milliseconds: 150), // Долгий глитч
```

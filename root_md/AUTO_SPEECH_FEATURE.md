# Автоматическая потоковая озвучка

## Обзор

Реализована система автоматической потоковой озвучки информации о достопримечательностях с минимальной задержкой и непрерывным воспроизведением.

## Ключевые особенности

### 1. Автоматический запуск
- Озвучка начинается автоматически при получении первого блока текста (минимум 100 символов)
- Не требует ручного нажатия кнопок
- Начинается как можно быстрее, не дожидаясь полной загрузки страницы

### 2. Потоковая обработка
- Текст разбивается на небольшие блоки (300-800 символов)
- Блоки добавляются в очередь по мере загрузки
- Озвучка начинается с первого доступного блока
- Параллельная подготовка следующих блоков во время воспроизведения текущего

### 3. Непрерывное воспроизведение
- Автоматический переход между блоками без пауз
- Озвучка всех секций по порядку: История → Факты → Практическая информация → Рекомендации
- Очередь работает в фоновом режиме

### 4. Разбиение текста
- Текст разбивается по предложениям для естественного звучания
- Размер блока: 300-800 символов (оптимально для быстрого старта и качества)
- Учитываются границы предложений для сохранения смысла

## Архитектура

### GoogleTTSService (обновлен)

**Новые возможности:**
- `addToQueue(text, languageCode)` - добавление текста в очередь озвучки
- `clearQueue()` - очистка очереди и остановка воспроизведения
- `hasQueuedItems` - проверка наличия элементов в очереди

**Внутренние компоненты:**
- `_queue` - очередь текстовых блоков для озвучки
- `_audioFiles` - список подготовленных аудиофайлов
- `_isQueueActive` - флаг активности очереди
- `_isProcessing` - флаг обработки текущего блока

**Процесс работы:**
```
1. Добавление текста → Разбиение на блоки → Добавление в очередь
2. Запуск очереди (если не активна)
3. Параллельно:
   - Синтез следующего блока (_prepareNextChunk)
   - Воспроизведение готового аудио (_playNextAudioFile)
4. Автоматический переход к следующему блоку
5. Цикл продолжается до опустошения очереди
```

### AttractionDetailsScreen (обновлен)

**Новые механизмы:**
- `_autoAddToSpeechQueue()` - автоматическое добавление секций в очередь
- `_monitorSpeechProgress()` - мониторинг состояния озвучки
- `_buildSpeechIndicator()` - индикатор активной озвучки

**Логика автоматической озвучки:**
```
1. Получение потока данных от API
2. Проверка каждой секции на новизну и достаточную длину (≥100 символов)
3. Автоматическое добавление новых секций в очередь TTS
4. Запуск мониторинга прогресса озвучки
5. Обновление UI индикатора
```

**Отслеживание прогресса:**
- Запоминание уже обработанных секций (`_lastProcessed*`)
- Предотвращение повторного добавления одинакового текста
- Мониторинг состояния воспроизведения каждые 500мс

### Очередь воспроизведения

```dart
Future<void> _startQueue() async {
  while (_isQueueActive && (hasMoreContent)) {
    // Подготовка следующего блока (если нужно)
    if (_audioFiles.isEmpty && _queue.isNotEmpty) {
      await _prepareNextChunk();
    }
    
    // Воспроизведение готового аудио
    if (_audioFiles.isNotEmpty) {
      await _playNextAudioFile();
    }
  }
}
```

## Производительность

### Время до начала озвучки:
- **До:** Полная загрузка всего текста + клик пользователя (10-30 секунд)
- **После:** Первый блок ~100 символов + синтез (~2-5 секунд)

### Непрерывность воспроизведения:
- Нет пауз между блоками
- Плавный переход между секциями
- Озвучка всего контента за один сеанс

### Использование памяти:
- Очистка воспроизведенных аудиофайлов
- Хранение только текущего и следующего блока
- Эффективное управление временными файлами

## Пользовательский опыт

1. **Пользователь открывает страницу достопримечательности**
   - Начинается загрузка текста (видно shimmer-эффект)
   - Отображается индикатор "⏳ Загрузка информации..."

2. **Получен первый блок текста (≥100 символов)**
   - Автоматически начинается озвучка
   - Индикатор меняется на "🎙️ Автоматическая озвучка активна"
   - Появляется кнопка остановки

3. **Во время озвучки**
   - Текст продолжает загружаться
   - Новые секции автоматически добавляются в очередь
   - Плавный переход между блоками

4. **Пользователь может**
   - Остановить озвучку в любой момент (кнопка ⏹️)
   - Прокручивать страницу и читать текст
   - Закрыть страницу (озвучка автоматически остановится)

## Обратная совместимость

- Сохранён метод `speak()` для ручной озвучки отдельных блоков
- Старый код продолжает работать
- Новая функциональность не ломает существующие интеграции

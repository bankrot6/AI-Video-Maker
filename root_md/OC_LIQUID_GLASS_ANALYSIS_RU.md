## 🚨 Критическая проблема

### API `oc_liquid_glass` ПОЛНОСТЬЮ отличается от `liquid_glass_renderer`!

#### Старый API (`liquid_glass_renderer`):
```dart
LiquidGlass(
  shape: LiquidRoundedSuperellipse(
    borderRadius: Radius.circular(12),
  ),
  settings: LiquidGlassSettings(
    thickness: 3,
    glassColor: Color(0x33FFFFFF),
    lightIntensity: 1.0,
    ambientStrength: 0.3,
    saturation: 1.0,
  ),
  child: Container(...),
)
```

#### Новый API (`oc_liquid_glass`):
```dart
OCLiquidGlassGroup(
  settings: OCLiquidGlassSettings(
    blendPx: 5,
    refractStrength: -0.06,
    distortFalloffPx: 45,
    distortExponent: 4,
    blurRadiusPx: 0,
    specAngle: 4,
    specStrength: 20.0,
    specPower: 100,
    specWidth: 10,
    lightbandOffsetPx: 10,
    lightbandWidthPx: 30,
    lightbandStrength: 0.9,
    lightbandColor: Colors.white,
  ),
  child: OCLiquidGlass(
    borderRadius: 12.0,  // DOUBLE, не BorderRadius!
    color: Color(0x33FFFFFF),
    child: Container(...),
  ),
)
```

### Ключевые различия:

| Параметр | liquid_glass_renderer | oc_liquid_glass |
|----------|----------------------|----------------|
| **Структура** | Один виджет | Группа + виджет |
| **Форма** | `shape: LiquidRoundedSuperellipse` | `borderRadius: double` |
| **Настройки** | `thickness`, `lightIntensity`, `saturation` | `blendPx`, `refractStrength`, `blurRadiusPx`, `specStrength`, и т.д. |
| **Цвет** | `glassColor: Color` | `color: Color` |
| **Сложность** | Простой | Очень сложный (много параметров шейдера) |

## 🔍 Требуемые изменения

### Масштаб работы:
- **15+ файлов** требуют обновления
- **50+ использований** LiquidGlass компонентов
- **Каждое использование** требует переписывания с нуля
- **Невозможно** автоматизировать конвертацию параметров

### Архитектурные изменения:
1. Все экраны должны быть обернуты в `OCLiquidGlassGroup`
2. Все параметры нужно конвертировать вручную в GPU-шейдерные параметры
3. Нет прямого соответствия параметров (например, `thickness` → `blurRadiusPx`?)
4. Потребуется экспериментальная настройка каждого компонента

# Инструкция по настройке VK Video API для ChatCoach

## Проблема

После добавления ключа в файл `.env` видео из ВКонтакте не отображаются в карточках упражнений.

## Причины

1. **Файл `.env` не создан** - он находится в `.gitignore` и должен быть создан вручную
2. **Неверный или отсутствующий токен доступа VK API**
3. **Токен не имеет необходимых прав доступа**

## Решение

### Шаг 1: Получение токена VK API

#### Вариант А: Сервисный ключ (Service Token)

Это самый простой способ для тестирования:

1. **Перейдите на страницу управления приложениями ВКонтакте:**
   - https://vk.com/apps?act=manage

2. **Создайте новое Standalone-приложение:**
   - Нажмите "Создать приложение"
   - Выберите тип: **Standalone-приложение**
   - Укажите название: `ChatCoach Exercise Videos`
   - Подтвердите создание

3. **Получите сервисный ключ:**
   - Откройте созданное приложение
   - Перейдите в раздел **"Настройки"**
   - Найдите секцию **"Сервисный ключ доступа"**
   - Скопируйте ключ (он выглядит как длинная строка из букв и цифр)

4. **Проверьте права доступа:**
   - Сервисный ключ должен иметь доступ к методу `video.search`
   - Обычно это право предоставляется автоматически

#### Вариант Б: Access Token (User Token)

Если вам нужны расширенные права:

1. **Используйте OAuth авторизацию:**
   ```
   https://oauth.vk.com/authorize?client_id={APP_ID}&scope=video&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token
   ```
   
   Замените `{APP_ID}` на ID вашего приложения.

2. **Разрешите доступ:**
   - Авторизуйтесь в ВКонтакте
   - Разрешите приложению доступ к видео
   - Скопируйте токен из адресной строки (после `access_token=`)

3. **Права доступа:**
   - Убедитесь, что параметр `scope` включает `video`

### Шаг 2: Создание файла `.env`

1. **Создайте файл `.env` в корневой директории проекта:**
   ```bash
   cd /путь/к/ChatCoach
   touch .env
   ```

2. **Скопируйте содержимое из `.env.example`:**
   ```bash
   cp .env.example .env
   ```

3. **Отредактируйте файл `.env` и добавьте ваш токен:**
   ```env
   # VK Video API Key
   VKVIDEO_SERVICE_KEY=ваш_токен_здесь
   ```

   Либо используйте альтернативные имена:
   ```env
   VK_API_TOKEN=ваш_токен_здесь
   # или
   VK_VIDEO_API_TOKEN=ваш_токен_здесь
   ```

### Шаг 3: Проверка

1. **Запустите приложение:**
   ```bash
   flutter run
   ```

2. **Проверьте логи при открытии карточки упражнения:**
   ```
   ✅ ENV: .env файл загружен
   🔍 AGGREGATOR: Начало поиска видео для: Приседания
   🔑 AGGREGATOR: VK API token present: true
   🔍 AGGREGATOR: Поиск VK видео по запросу: "Приседания техника выполнения"
      Найдено результатов: 15
   ✅ AGGREGATOR: Отобрано 4 видео из 48 кандидатов
   ```

3. **Ожидаемое поведение:**
   - В карточке упражнения должна появиться карусель с изображением и 1-4 видео
   - Свайп вправо переключает между изображением и видео
   - Видео воспроизводится при нажатии на плеер

## Типичные ошибки и их решение

### Ошибка 1: "VK API токен отсутствует"

**Лог:**
```
⚠️ AGGREGATOR: VK API токен отсутствует! Видео не будут загружены.
💡 AGGREGATOR: Добавьте VKVIDEO_SERVICE_KEY в файл .env
```

**Решение:**
- Убедитесь, что файл `.env` создан в корне проекта
- Проверьте, что токен добавлен как `VKVIDEO_SERVICE_KEY=...`
- Перезапустите приложение после добавления токена

### Ошибка 2: "Неверный токен доступа"

**Лог:**
```
❌ VK_API error: User authorization failed (код: 5)
   💡 Неверный токен доступа! Проверьте VKVIDEO_SERVICE_KEY в .env
```

**Решение:**
- Проверьте, что токен скопирован полностью (без пробелов)
- Убедитесь, что токен не истек
- Получите новый токен через https://vk.com/apps?act=manage

### Ошибка 3: "Доступ запрещен"

**Лог:**
```
❌ VK_API error: Access denied (код: 15)
   💡 Доступ запрещен! Токен не имеет прав на video.search
```

**Решение:**
- Используйте сервисный ключ вместо пользовательского токена
- Или получите новый токен с правами `video` (см. Вариант Б выше)

### Ошибка 4: "Видео не найдены"

**Лог:**
```
✅ AGGREGATOR: Отобрано 0 видео из 0 кандидатов
```

**Решение:**
- Это нормально для редких или специфических упражнений
- Попробуйте популярные упражнения: "Приседания", "Отжимания", "Планка"
- VK API может вернуть мало результатов для некоторых запросов

## Структура проекта

### Файлы, отвечающие за VK Video:

```
lib/
├── services/
│   ├── vk_api_client.dart          # Клиент для VK API video.search
│   ├── video_aggregator_service.dart # Агрегатор для поиска видео
│   └── vk_video_search_service.dart  # Старый сервис (веб-скрейпинг)
├── models/
│   └── exercise_video_candidate.dart # Модель видео-кандидата
└── features/exercise/
    ├── exercise_details_screen.dart  # Экран с карточкой упражнения
    ├── exercise_providers.dart       # Провайдеры для видео
    └── vk_video_keep_alive.dart      # Виджет для воспроизведения VK видео
```

### Логика работы:

1. **Пользователь открывает карточку упражнения**
   → `ExerciseDetailsScreen`

2. **Запускается поиск видео**
   → `VideoAggregatorService.searchCandidates()`

3. **Поиск через VK API**
   → `VkApiClient.searchVideos()`
   - Проверяет наличие токена
   - Выполняет запрос к `video.search`
   - Парсит результаты

4. **Ранжирование результатов**
   - По количеству просмотров (↓)
   - По оптимальной длительности (~120-240 сек)

5. **Отображение в UI**
   - Карусель с изображением + 1-4 видео
   - WebView embed плеер VK Video

## Приоритеты загрузки токена

Код проверяет переменные окружения в следующем порядке:

1. `.env` файл:
   - `VKVIDEO_SERVICE_KEY` (приоритет)
   - `VK_API_TOKEN`
   - `VK_VIDEO_API_TOKEN`

2. `dart-define` (если запускается с флагами):
   ```bash
   flutter run --dart-define=VKVIDEO_SERVICE_KEY=your_token
   ```

3. **Fallback** (если `.env` не найден):
   - `test_vk_key` (не работает с реальным API)

## Официальная документация VK API

### Полезные ссылки:

1. **VK API Reference:**
   - https://dev.vk.com/

2. **Метод video.search:**
   - https://dev.vk.com/method/video.search

3. **Управление приложениями:**
   - https://vk.com/apps?act=manage

4. **OAuth авторизация:**
   - https://dev.vk.com/api/access-token/getting-started

### Параметры метода video.search:

```
GET https://api.vk.com/method/video.search

Параметры:
- q: string - поисковой запрос
- count: integer (1-200) - количество результатов
- adult: integer (0/1) - включать контент 18+
- extended: integer (0/1) - расширенная информация
- v: string - версия API (5.199)
- access_token: string - токен доступа
```

## Альтернативное решение: веб-скрейпинг

Если у вас нет токена VK API, можно использовать старый метод (веб-скрейпинг):

1. **Используйте `VkVideoSearchService` вместо `VideoAggregatorService`**

2. **Измените `exercise_details_screen.dart`:**
   ```dart
   // Вместо:
   final aggregator = ref.read(videoAggregatorServiceProvider);
   
   // Используйте:
   final vkSearch = ref.read(vkVideoSearchServiceProvider);
   final videoData = await vkSearch.searchVideo(exerciseName);
   ```

3. **Преимущества:**
   - ✅ Не требует токена
   - ✅ Работает из коробки

4. **Недостатки:**
   - ❌ Менее надежный
   - ❌ Может сломаться при изменении HTML VK
   - ❌ Только 1 видео (не 4)
   - ❌ Нет метаданных (просмотры, длительность)

## Резюме

1. **Создайте приложение на https://vk.com/apps?act=manage**
2. **Получите сервисный ключ**
3. **Создайте файл `.env` с ключом `VKVIDEO_SERVICE_KEY=...`**
4. **Перезапустите приложение**
5. **Проверьте логи на наличие видео**

Если проблема сохраняется, проверьте логи на ошибки VK API и убедитесь, что токен имеет необходимые права.

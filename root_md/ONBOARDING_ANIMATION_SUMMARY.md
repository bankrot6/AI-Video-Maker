# Анимация кнопок на онбординге

## Описание изменений

Добавлена анимация "разворачивания" (scale) для всех кнопок-капсул на экране онбординга. Кнопки появляются с эффектом масштабирования от 0 до 1, как у встроенной анимации FloatingActionButton в Flutter.

## Реализованная функциональность

### 1. Система анимации
- **Scale эффект**: Кнопки "разворачиваются" от центра (scale от 0.0 до 1.0)
- **Без смещения**: Кнопки появляются строго на своём месте
- **Последовательное появление**: Каждая кнопка появляется с задержкой 50ms после предыдущей
- **Длительность**: Общая анимация длится 350ms
- **Кривая**: `Curves.easeOut` с использованием `Interval` для задержек
- **Как у FAB**: Анимация идентична встроенной анимации FloatingActionButton

### 2. Применение на страницах

Анимация применена к следующим страницам онбординга:

1. **Страница выбора пола (индекс 0)**
   - 2 кнопки: "Мужской", "Женский"

2. **Страница выбора цели (индекс 1)**
   - 2 кнопки: "Набрать массу", "Похудеть"

3. **Страница выбора места тренировок (индекс 2)**
   - 2 кнопки: "Дома", "В зале"

4. **Страница выбора уровня опыта (индекс 4)**
   - 3 кнопки: "Новичок", "Средний", "Атлет"

5. **Страница выбора дополнительного фокуса (индекс 8)**
   - 6 кнопок с акцентами: "Руки", "Грудь", "Спина", "Ноги", "Жиросжигание", "Пресс"
   - 1 кнопка управления: "Продолжить" / "Пропустить"

### 3. Технические детали

#### Использованные компоненты:
- `TickerProviderStateMixin` для поддержки анимации
- Один `AnimationController` на весь экран онбординга
- `ScaleTransition` для эффекта разворачивания (как у FAB)
- `Interval` для создания задержки между кнопками
- `Tween<double>` для интерполяции от 0.0 до 1.0

#### Поведение:
- Анимация запускается автоматически при первом построении экрана
- При переходе между страницами анимация перезапускается через `_resetButtonAnimation()`
- Каждая кнопка имеет задержку: `index * 50ms`
- Используется `Interval` для плавного распределения анимации

#### Код анимации:
```dart
Widget _buildAnimatedButton({
  required Widget child,
  required int index,
}) {
  final delay = index * 50; // 50ms задержка между кнопками
  final animation = Tween<double>(
    begin: 0.0,
    end: 1.0,
  ).animate(
    CurvedAnimation(
      parent: _buttonAnimationController,
      curve: Interval(
        (delay / 350).clamp(0.0, 1.0),
        1.0,
        curve: Curves.easeOut,
      ),
    ),
  );

  // ScaleTransition для эффекта "разворачивания" как у FAB
  return ScaleTransition(
    scale: animation,
    child: child,
  );
}
```

## Преимущества реализации

1. **Естественный эффект**: Анимация идентична встроенной анимации FAB (разворачивание)
2. **Без "прыжков"**: Кнопки разворачиваются строго на своём месте
3. **Плавность**: Последовательное появление создаёт приятный визуальный поток
4. **Производительность**: Используется один контроллер для всех кнопок
5. **Простота**: Понятная и легко модифицируемая логика

## Жизненный цикл анимации

1. **Инициализация**: Контроллер создаётся в `initState()`
2. **Первый запуск**: Анимация запускается через `addPostFrameCallback()`
3. **Смена страницы**: При `onPageChanged` вызывается `_resetButtonAnimation()`
4. **Очистка**: Контроллер удаляется в `dispose()`

## Настройка параметров

Для изменения скорости или задержки анимации:
- Длительность: изменить `duration` в `AnimationController` (по умолчанию 350ms)
- Задержка между кнопками: изменить множитель в `index * 50` (по умолчанию 50ms)
- Кривая: изменить `Curves.easeOut` на другую кривую
- Тип анимации: используется `ScaleTransition` для эффекта разворачивания

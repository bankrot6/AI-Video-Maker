# VK Video - Краткая инструкция

## ✅ Реализовано

### Используем VK Video для отображения видео с упражнениями

## Почему VK Video?

1. ✅ **Работает в России** без ограничений (в отличие от YouTube)
2. ✅ **Много фитнес-контента** - большая база видео с упражнениями
3. ✅ **Стабильный плеер** - надежная работа
4. ✅ **Чистый интерфейс** - только плеер, без лишнего UI
5. ✅ **Быстрая загрузка** - оптимизировано для РФ

## Как работает

### Embed URL формат:
```
https://vk.com/video_ext.php?oid={owner_id}&id={video_id}&hd=2&autoplay=0
```

### Параметры:
- `oid` - ID владельца (отрицательный для групп)
- `id` - ID видео
- `hd=2` - HD качество
- `autoplay=0` - без автозапуска

### Поиск:
1. Запрос: `"как делать [упражнение] упражнение техника"`
2. Поиск через веб-интерфейс VK
3. Парсинг первого результата
4. Формирование embed URL
5. Отображение в WebView

# 🎯 Обновление: Последовательная анимация

## ✨ Что добавлено

### Новое поведение:
Кнопки с ответами теперь **появляются только после завершения печати заголовка**!

## 🎬 Последовательность анимации

### Раньше:
```
Страница загружается
  ↓
Заголовок печатается → Кнопки сразу видны
```

### Теперь:
```
Страница загружается
  ↓
Заголовок печатается с глитчем
  ↓
Печать завершена
  ↓
Кнопки появляются с анимацией! ✨
```

## 📝 Технические изменения

### 1. Виджет `TypewriterGlitchText`
**Добавлено:**
- Параметр `onTypingComplete` - callback, вызываемый по завершении печати

```dart
TypewriterGlitchText(
  text: 'Какой ваш пол?',
  onTypingComplete: () {
    // Показываем кнопки
  },
)
```

### 2. Файл `onboarding_screen.dart`
**Добавлено:**
- Флаг `_isTypingComplete` - отслеживает завершение печати
- Логика скрытия кнопок до завершения печати
- Автоматический запуск анимации кнопок после печати

**Изменено:**
- `_buildAnimatedButton()` - теперь возвращает невидимые кнопки до завершения печати
- `_resetButtonAnimation()` - сбрасывает флаг при смене страницы
- `_shouldShowNextFab()` - FAB кнопка также появляется после печати
- `initState()` - убран автозапуск анимации кнопок

## 🎨 Визуальный эффект

### Шаг 1: Печать заголовка
```
К... [ГЛИТЧ] ...акой в... [ГЛИТЧ] ...аш пол?
```

### Шаг 2: Появление кнопок (через 50мс после завершения печати)
```
Какой ваш пол?

[Мужской]     ← появляется первой
    ↓ 50ms
[Женский]     ← появляется второй
```

## ⏱️ Тайминги

1. **Печать текста**: ~50мс на символ
2. **Глитч**: 80мс при срабатывании
3. **Задержка до кнопок**: минимальная (сразу после печати)
4. **Анимация кнопок**: 50мс задержка между кнопками

### Пример для заголовка "Какой ваш пол?" (14 символов):
- Печать: ~700мс (14 × 50мс)
- Глитчи: +80-240мс (случайно)
- **Итого**: ~0.7-1 секунда до появления кнопок

## 🚀 Преимущества

✅ **Лучше UX**: пользователь сначала читает вопрос, потом видит ответы  
✅ **Больше внимания к тексту**: заголовок не конкурирует с кнопками  
✅ **Плавная последовательность**: всё происходит в логичном порядке  
✅ **Футуристичнее**: система "думает", потом предлагает варианты

## 🔧 Если нужно вернуть старое поведение

В `onboarding_screen.dart` можно сделать кнопки видимыми сразу:

```dart
// В initState() добавить:
_isTypingComplete = true; // Кнопки сразу видны

// Или в onTypingComplete удалить:
setState(() {
  _isTypingComplete = true;  // ← закомментировать эту строку
});
```

# Недельные фокусы - Быстрый старт

## Что реализовано? 🎯

Улучшенная система генерации тренировок на неделю с учетом выбранных пользователем групп мышц и автоматической фоновой загрузкой остальных дней.

## Проблемы которые решены ✅

### Было:
- ❌ Повторение упражнений в разные дни
- ❌ Долгое ожидание генерации всех дней
- ❌ Нет учета выбранных фокусов из онбоардинга
- ❌ Генерация только первого дня, остальные не всегда генерируются

### Стало:
- ✅ Каждый день имеет свой фокус (грудь, ноги, спина и т.д.)
- ✅ Упражнения не повторяются между днями
- ✅ Первый день генерируется сразу с потоковым отображением
- ✅ Остальные дни генерируются в фоне на главной странице
- ✅ Потоковое отображение каждого дня по мере готовности

## Как работает? 🚀

### 1. Онбоардинг
```
Пользователь выбирает:
- Количество дней: 3
- Фокусы: Грудь, Ноги, Спина

Система создает план:
День 1 → Грудь
День 2 → Ноги  
День 3 → Спина
```

### 2. Генерация первого дня
```
🏋️ Генерируется День 1 (Грудь)
📝 Упражнения появляются по одному (поток)
✅ Первый день готов → переход на главную
```

### 3. Фоновая генерация на главной странице
```
🔄 Автоматически запускается генерация Дня 2
📝 Упражнения появляются постепенно
✅ День 2 готов

🔄 Автоматически запускается генерация Дня 3
📝 Упражнения появляются постепенно
✅ День 3 готов
```


### Умный промт для LLM
```
WEEKLY FOCUS PLAN:
day_1: chest
day_2: legs
day_3: back
```
LLM видит план на всю неделю и избегает повторений!

### Фоновый сервис генерации
```dart
BackgroundWorkoutGenerationService()

```
Генерирует дни 2-N с потоковым отображением

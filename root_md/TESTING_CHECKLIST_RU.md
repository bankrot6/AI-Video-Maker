# ✅ Чеклист тестирования потокового отображения

## 📋 Перед началом

- [ ] Flutter SDK установлен и актуален
- [ ] Устройство/эмулятор запущен
- [ ] Интернет доступен (для LLM)
- [ ] Консоль открыта для просмотра логов
- [ ] Приложение удалено (для чистого теста)

## 🧪 Тест 1: Первый запуск (новый пользователь)

### Действия:
1. [ ] Установите приложение
2. [ ] Запустите: `flutter run --debug`
3. [ ] Пройдите онбоардинг:
   - [ ] Выберите **3 дня** тренировок в неделю
   - [ ] Выберите **3 группы мышц** (грудь, ноги, спина)
4. [ ] Дождитесь генерации первого дня
5. [ ] Перейдите на главную страницу

### Ожидаемое поведение:
- [ ] **День 1**: Отображается сразу (6 упражнений)
- [ ] **День 2**: Начинает генерироваться в фоне
  - [ ] Заголовок появляется через ~2-5 секунд
  - [ ] Упражнения появляются **по одному** (не сразу все)
  - [ ] **НЕТ дубликатов** (не 6 одинаковых упражнений)
  - [ ] Шиммеры показываются для ожидающих упражнений
- [ ] **День 3**: Начинает генерироваться после дня 2
  - [ ] Пауза ~500мс между днем 2 и 3
  - [ ] Аналогичное потоковое отображение

### Логи в консоли:
```
[ ] ═══════════════════════════════════════════
[ ] 🏋️ ФОНОВАЯ ГЕНЕРАЦИЯ: День 2/3 НАЧАЛО
[ ] 🔑 Ключ провайдера: workout_day_..._1
[ ] 🧹 Провайдер очищен
[ ] ▶️ Стриминг запущен
[ ] 📝 День 2: Заголовок → "..."
[ ] ➕ День 2: Упражнение → "..."
[ ] ⏹️ Стриминг завершен
[ ] ✅ ФОНОВАЯ ГЕНЕРАЦИЯ: День 2/3 ЗАВЕРШЕН
[ ] ⏸️ Пауза 500мс перед следующим днем...
```

## 🧪 Тест 2: Переключение между днями

### Действия:
1. [ ] Находясь на главной странице
2. [ ] Свайпните влево/вправо для перехода на день 2
3. [ ] Подождите 3-5 секунд
4. [ ] Свайпните для перехода на день 3

### Ожидаемое поведение:
- [ ] **День 2**:
  - [ ] Если генерация завершена → показывает все упражнения
  - [ ] Если идет генерация → показывает упражнения по мере появления
  - [ ] **НЕТ мигания** или перезаписи упражнений
- [ ] **День 3**:
  - [ ] Если генерация завершена → показывает все упражнения
  - [ ] Если идет генерация → показывает упражнения по мере появления

---

## 🧪 Тест 3: Прерывание генерации

### Действия:
1. [ ] Запустите генерацию (как в тесте 1)
2. [ ] Во время генерации дня 2 **сверните приложение** (home button)
3. [ ] Подождите 10 секунд
4. [ ] Откройте приложение снова

### Ожидаемое поведение:
- [ ] Приложение возобновляет работу
- [ ] Если день 2 не был завершен → запускается fallback генерация
- [ ] Логи показывают `🔄 HOME: Запускаем догрузку недостающих дней...`
- [ ] День 2 генерируется с чистого листа (новый запрос к LLM)

---

## 🧪 Тест 4: Повторный вход

### Действия:
1. [ ] Полностью закройте приложение (kill app)
2. [ ] Откройте приложение снова
3. [ ] Перейдите на главную страницу

### Ожидаемое поведение:
- [ ] **Все дни (1, 2, 3)** загружаются из кэша (SharedPreferences)
- [ ] **НЕТ повторной генерации** (все уже готово)
- [ ] Упражнения отображаются мгновенно
- [ ] Логи показывают: `✅ HOME: Все 3 дней готовы`

---

## 🧪 Тест 5: Изменение количества дней

### Действия:
1. [ ] Зайдите в настройки профиля
2. [ ] Измените количество дней с **3 на 5**
3. [ ] Вернитесь на главную страницу
4. [ ] Свайпните к дням 4 и 5

### Ожидаемое поведение:
- [ ] Дни 1-3 уже готовы (из кэша)
- [ ] Дни 4-5 начинают генерироваться
- [ ] Потоковое отображение для дней 4-5

---

## 🧪 Тест 6: Проверка дубликатов (специальный)

### Действия:
1. [ ] Очистите приложение (удалите и переустановите)
2. [ ] Пройдите онбоардинг
3. [ ] Перейдите на главную
4. [ ] **СРАЗУ** свайпните на день 2 (пока генерируется)
5. [ ] **Внимательно смотрите** на первые 5 секунд

### Что НЕ должно происходить:
- [ ] ❌ 6 карточек с одинаковым названием упражнения
- [ ] ❌ Карточки "мигают" или меняются местами
- [ ] ❌ Упражнение появляется, затем исчезает, затем появляется снова

### Что должно происходить:
- [ ] ✅ Заголовок + шиммеры
- [ ] ✅ Первое упражнение появляется (заменяет шиммер)
- [ ] ✅ Второе упражнение появляется (заменяет шиммер)
- [ ] ✅ И так далее, **по одному**

---

## 🧪 Тест 7: Стресс-тест (медленная сеть)

### Действия:
1. [ ] Включите ограничение скорости сети (Settings → Developer Options → Limit to 2G)
2. [ ] Запустите генерацию дней
3. [ ] Наблюдайте за поведением

### Ожидаемое поведение:
- [ ] Генерация идет **медленнее**, но без ошибок
- [ ] Упражнения все равно появляются по одному
- [ ] UI не зависает (можно взаимодействовать)
- [ ] Шиммеры показываются для ожидающих упражнений

---

## 🧪 Тест 8: Ошибка сети (нет интернета)

### Действия:
1. [ ] **Отключите интернет**
2. [ ] Запустите генерацию дней
3. [ ] Наблюдайте за поведением

### Ожидаемое поведение:
- [ ] День 1 (из онбоардинга) должен быть готов (из кэша)
- [ ] Дни 2-3 не генерируются (нет интернета)
- [ ] Логи показывают ошибку: `🔴 ФОНОВАЯ ГЕНЕРАЦИЯ: Ошибка дня X: ...`
- [ ] **Приложение не крашится**
- [ ] **Включите интернет** → генерация возобновляется (fallback)

---

## 🧪 Тест 9: Разные группы мышц

### Действия:
1. [ ] Очистите приложение
2. [ ] Пройдите онбоардинг с **разными группами мышц**:
   - День 1: Грудь
   - День 2: Ноги
   - День 3: Спина
3. [ ] Проверьте что упражнения соответствуют

### Ожидаемое поведение:
- [ ] **День 1**: Упражнения на грудь (жим, разводка, ...)
- [ ] **День 2**: Упражнения на ноги (приседания, выпады, ...)
- [ ] **День 3**: Упражнения на спину (подтягивания, тяги, ...)
- [ ] **Нет повторений** упражнений между днями

## 🎯 Критерии успеха

### ✅ PASS (тест пройден):
- Все тесты отмечены как [ X ]
- Нет дубликатов упражнений
- Упражнения появляются по одному
- Логи соответствуют ожидаемым
- Приложение не крашится

### ❌ FAIL (тест не пройден):
- Хотя бы один тест не пройден
- Дубликаты упражнений появляются
- Упражнения появляются все сразу
- Ошибки в логах
- Приложение крашится

# AI-Агент Тренер - Руководство

## Обзор

Реализован полноценный AI-агент тренера в чате, который может:

✅ **Видеть всю программу тренировок** - агент получает данные о недельных планах  
✅ **Анализировать прогресс** - видит историю выполнения упражнений, объемы, процент выполнения  
✅ **Предлагать упражнения** - может рекомендовать конкретные упражнения с параметрами  
✅ **Добавлять упражнения в план** - пользователь может добавить предложенное упражнение одним нажатием  

## Архитектура

#### Расширенная модель `ChatMessage`
```dart

```

### 2. Парсер (`lib/features/ai_chat/utils/`)

#### `exercise_suggestion_parser.dart`
Извлекает предложения упражнений двумя способами:

**JSON формат** (предпочтительный):
```json
{
  "exerciseSuggestions": [
    {
      "id": "unique_id",
      "exercise": {
        "name": "Жим лежа",
        "sets": 3,
        "reps": 12,
        "weightKg": 60.0
      },
      "reasoning": "Базовое упражнение для развития груди",
      "targetDayIndex": 0,
      "targetDayTitle": "День груди"
    }
  ]
}
```

**Текстовый формат** (fallback):
- "Жим лежа: 3 подхода по 12 повторений, 60 кг"
- "Приседания - 4x10 @ 80kg"

## Использование

### Для пользователя

1. Спросите AI о программе тренировок:
   - "Составь программу на грудь"
   - "Какие упражнения добавить для спины?"
   - "Нужна замена жима лежа"

2. AI предложит упражнения с карточками

3. Нажмите "Добавить в тренировку" на нужном упражнении

4. Упражнение автоматически добавится в текущую неделю

### Пример диалога

**Пользователь:** "Хочу развить грудь, что посоветуешь?"

**AI:** "Для развития груди рекомендую следующие упражнения:

💪 **Моя рекомендация**
- Жим лежа - базовое упражнение для массы
- Жим гантелей под углом - акцент на верх груди
- Разводки - для изоляции и формы

```json
{
  "exerciseSuggestions": [
    {
      "id": "bench_press_1",
      "exercise": {
        "name": "Жим лежа",
        "sets": 4,
        "reps": 10,
        "weightKg": 60.0
      },
      "reasoning": "Базовое упражнение для общей массы грудных",
      "targetDayIndex": 0,
      "targetDayTitle": "День груди"
    }
  ]
}
```"

**Результат:** Появляется карточка с упражнением и кнопкой добавления

## Технические детали

### Интеграция в существующий код

1. **Провайдер агрегатора данных** обновлен для включения workout repositories
2. **ChatNotifier** расширен методами работы с упражнениями
3. **MessageBubble** автоматически показывает предложения под сообщениями AI
4. **Freezed модель** регенерирована с новым полем

### Обработка ошибок

- Если план недели не существует - создается автоматически
- При ошибке добавления показывается системное сообщение
- После успешного добавления - подтверждение в чате

### Производительность

- Парсинг упражнений кэшируется на уровне сообщения
- Репозитории workout используют SharedPreferences
- Инвалидация провайдеров только при изменениях

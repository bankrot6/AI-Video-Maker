# Исправление карусели с видео

## Проблема
Пользователь не видел карусель для пролистывания между фото и видео.

## Причина
VK Video поиск через веб-скрейпинг может не всегда находить видео, поэтому карусель могла показывать только 1 страницу (изображение).

## Решение

### 1. Улучшен поиск видео
Используется агрегатор для поиска через Яндекс, который находит VK видео с высокой вероятностью.

### 2. Добавлена визуальная подсказка
На первой странице (изображение) показывается подсказка **"Свайп для видео"**:

```dart
if (hasVideo && _currentPage == 0)
  Positioned(
    top: 16,
    right: 16,
    child: Container(
      child: Row(
        children: [
          Icon(Icons.swipe),
          Text('Свайп для видео'),
        ],
      ),
    ),
  ),
```

### 3. Добавлено логирование
Для отладки добавлены логи:

```dart
debugPrint('📸 IMAGE_SECTION: hasVideo=$hasVideo, pageCount=$pageCount');
debugPrint('📄 PAGE_VIEW: Переключено на страницу $index');
```

## Как работает карусель

### Логика:
1. **Загружаются изображение И видео** параллельно
2. **Если видео найдено** (`_videoUrl != null`):
   - `pageCount = 2`
   - Показываются индикаторы (точки)
   - Показывается подсказка "Свайп для видео"
   - Можно свайпать влево/вправо
3. **Если видео НЕ найдено**:
   - `pageCount = 1`
   - Только изображение, без свайпа

### UI элементы:

#### На странице 1 (изображение):
- 📸 Изображение упражнения
- 💡 Подсказка "Свайп для видео" (если есть видео)
- ⚪️ Индикаторы страниц внизу

#### На странице 2 (видео):
- 🎥 Видеоплеер VK
- 🎬 Метка "Видео" справа вверху
- ⚪️ Индикаторы страниц внизу

## Стратегия поиска видео

### Подход:
1. **VK Video база** (проверенные видео для популярных упражнений)
2. **Поиск через Яндекс** (агрегатор находит VK видео)

### Преимущества:
- ✅ Высокая вероятность найти видео
- ✅ VK - качественный контент
- ✅ Карусель работает стабильно

## Примеры логов

### Успешный поиск VK:
```
🎥 EXERCISE_DETAILS: Поиск видео для: Приседания
✅ EXERCISE_DETAILS: VK видео найдено: https://vk.com/video_ext.php?...
📸 IMAGE_SECTION: hasVideo=true, pageCount=2, videoUrl=https://vk.com/video_ext.php?...
```

### Поиск через агрегатор:
```
🎥 EXERCISE_DETAILS: Поиск видео для: Скручивания
⚠️ EXERCISE_DETAILS: Ищем через агрегатор...
✅ AGGREGATOR: Найдено видео через Яндекс
📸 IMAGE_SECTION: hasVideo=true, pageCount=2
```

### Видео не найдено:
```
🎥 EXERCISE_DETAILS: Поиск видео для: Неизвестное упражнение
❌ EXERCISE_DETAILS: Видео не найдено
📸 IMAGE_SECTION: hasVideo=false, pageCount=1
```

## Проверка

### Карусель работает если:
- [x] Видны точки-индикаторы внизу
- [x] Видна подсказка "Свайп для видео" справа вверху
- [x] Можно свайпнуть влево
- [x] На второй странице видео воспроизводится
- [x] Метка "Видео" видна на второй странице

### Если карусель не работает:
1. Проверьте логи - найдено ли видео?
2. Если `hasVideo=false` - видео не найдено
3. Если `hasVideo=true` но не свайпается - проблема с WebView

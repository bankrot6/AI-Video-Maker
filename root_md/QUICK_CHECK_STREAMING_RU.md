# 🚀 Быстрая проверка потокового отображения

## Что исправлено

- ✅ **Дубликаты упражнений**: Исправлена проверка при добавлении упражнений
- ✅ **Перезапись данных**: `complete()` больше не затирает промежуточные данные
- ✅ **Очистка состояния**: Явный вызов `reset()` перед каждым днем
- ✅ **Задержки**: 100мс после очистки, 500мс между днями
- ✅ **Унифицированные ключи**: `workout_day_{timestamp}_{dayIndex}` везде

## Как проверить

### 1. Запустите приложение
```bash
flutter run
```

### 2. Пройдите онбоардинг
- Выберите 3 дня тренировок в неделю
- Выберите несколько групп мышц (например, грудь, ноги, спина)
- Дождитесь генерации первого дня

### 3. Перейдите на главную страницу
- День 1 должен отображаться сразу (был сгенерирован на онбоардинге)
- Дни 2 и 3 начнут генерироваться в фоне

### 4. Следите за консолью
Вы должны увидеть:

```

🧹 Провайдер очищен
▶️ Стриминг запущен
📝 День 2: Заголовок → "Тренировка день 2"
➕ День 2: Упражнение → "Жим штанги лежа"
➕ День 2: Упражнение → "Разводка гантелей"
```

### 5. Проверьте UI

#### День 2:
1. Переключитесь на день 2 через свайп
2. Должны увидеть:
   - Сначала заголовок (шиммер или текст)
   - Затем упражнения появляются **по одному**
   - Шиммеры для оставшихся упражнений
   - **НЕТ дубликатов**

#### День 3:
1. Переключитесь на день 3 через свайп
2. Должны увидеть:
   - Аналогичное поведение как на дне 2
   - Упражнения появляются **постепенно**
   - **НЕТ долгой загрузки** с шиммерами

## ❌ Что НЕ должно происходить

- ❌ Дубликаты упражнений (6 одинаковых карточек)
- ❌ Долгая загрузка шиммеров без изменений
- ❌ Все упражнения появляются одновременно
- ❌ Упражнения "мигают" или перезаписываются

## ✅ Ожидаемое поведение

- ✅ Каждое упражнение появляется по мере получения от LLM
- ✅ Нет дубликатов
- ✅ Плавная пауза между генерацией дней
- ✅ Подробные логи в консоли

## 🐛 Если что-то не так

### Проблема: Дубликаты все еще появляются

**Возможная причина**: Старый кэш провайдеров

**Решение**: 
```bash
# Перезапустите приложение с hot restart
flutter run
# или нажмите "R" в консоли Flutter
```

### Проблема: Упражнения не появляются

**Возможная причина**: Ошибка в LLM или сети

**Решение**: Проверьте консоль на наличие ошибок:
```
🔴 ФОНОВАЯ ГЕНЕРАЦИЯ: Ошибка дня X: ...
```

### Проблема: Логи не отображаются

**Возможная причина**: Логирование отключено

**Решение**: Убедитесь что запускаете в debug режиме:
```bash
flutter run --debug
```

## 📱 Тестирование на разных сценариях

### Сценарий А: Первый запуск
1. Удалите приложение
2. Установите заново
3. Пройдите онбоардинг
4. → Дни 2-N должны генерироваться на главной странице

### Сценарий Б: Повторный вход
1. Закройте приложение
2. Откройте снова
3. → Все дни должны быть уже готовы (загружаются из кэша)

### Сценарий В: Прерывание генерации
1. Начните генерацию дней
2. Сверните приложение
3. Откройте снова
4. → Недостающие дни должны начать генерироваться (fallback)

## 📊 Ключевые метрики

- **Время до первого упражнения**: ~2-5 секунд после начала генерации
- **Задержка между упражнениями**: ~1-3 секунды (зависит от LLM)
- **Задержка между днями**: 500мс (фиксированная)
- **Задержка после очистки**: 100мс (фиксированная)

# 🎙️ Инструкция: Автоматическая Озвучка

## Для Пользователей

### Как Это Работает?

1. **Откройте любую достопримечательность** в приложении
2. **Озвучка начнётся автоматически** через несколько секунд
3. **Слушайте информацию** пока прокручиваете текст
4. **Остановите в любой момент** кнопкой ⏹️ вверху экрана

**Никаких действий не требуется** - всё работает автоматически!

## Для Разработчиков

### Быстрый Старт

#### 1. Использование в Новых Экранах

Если вы хотите добавить автоматическую озвучку в новый экран:

```dart
import 'package:aivideomaker/services/text_to_speech/google_tts_service.dart';

class MyScreen extends ConsumerStatefulWidget {
  @override
  ConsumerState<MyScreen> createState() => _MyScreenState();
}

class _MyScreenState extends ConsumerState<MyScreen> {
  late final GoogleTTSService _ttsService;

  @override
  void initState() {
    super.initState();
    _ttsService = GoogleTTSService();
  }

  @override
  void dispose() {
    _ttsService.clearQueue();
    _ttsService.dispose();
    super.dispose();
  }

  void _startAutoSpeech(String text) {
    // Автоматически разобьётся на блоки и начнёт озвучиваться
    _ttsService.addToQueue(text, languageCode: 'ru-RU');
  }

  void _stopAutoSpeech() {
    _ttsService.clearQueue();
  }
}
```

#### 2. Настройка Параметров Разбиения

В `GoogleTTSService` можно настроить размер блоков:

```dart
// В методе _splitIntoChunks()

const maxChunkLength = 800;  // Максимальный размер блока
// Уменьшите для более быстрого старта

if (currentChunk.length >= 300) {  // Минимальный размер блока
  // Увеличьте для меньшего количества API запросов
  chunks.add(currentChunk.toString().trim());
  currentChunk = StringBuffer();
}
```

#### 3. Использование Ручной Озвучки

Если нужна ручная озвучка одного блока (без очереди):

```dart
final ttsService = GoogleTTSService();

// Озвучить весь текст сразу (старый способ)
await ttsService.speak(
  "Текст для озвучки",
  languageCode: 'ru-RU',
  useSSML: false,
);
```

#### 4. Отслеживание Статуса

```dart
// Проверка, идёт ли озвучка
if (ttsService.isPlaying) {
  print('Озвучка активна');

// Проверка, есть ли элементы в очереди
if (ttsService.hasQueuedItems) {
  print('В очереди есть блоки для озвучки');

```

### Настройка Параметров Синтеза

В методе `_synthesizeSpeech()` можно настроить качество голоса:

```dart
'audioConfig': {
  'audioEncoding': 'OGG_OPUS',      // Формат аудио
  'pitch': -1.5,                     // Тон голоса (-20.0 до 20.0)
  'speakingRate': 0.92,              // Скорость речи (0.25 до 4.0)
  'volumeGainDb': 3.0,               // Громкость (до 16.0 dB)
  'effectsProfileId': [              // Эффекты для разных устройств
    'headphone-class-device',
    'large-home-entertainment-class-device',
  ],
  'sampleRateHertz': 48000,          // Частота дискретизации
}
```

### Выбор Голоса

Добавьте новые языки/голоса в метод `_getVoiceName()`:

```dart
String _getVoiceName(String languageCode) {
  switch (languageCode) {
    case 'ru-RU':
      return 'ru-RU-Wavenet-E';  // Женский голос WaveNet
      // Альтернативы:
      // 'ru-RU-Wavenet-A' - мужской
      // 'ru-RU-Wavenet-B' - мужской
      // 'ru-RU-Wavenet-C' - женский
      // 'ru-RU-Wavenet-D' - мужской
    
    case 'en-US':
      return 'en-US-Neural2-F';
    
    // Добавьте свой язык:
    case 'uk-UA':
      return 'uk-UA-Wavenet-A';
    
    default:
      return 'en-US-Neural2-F';
  }
}
```

### Пример Полной Интеграции

```dart
class ArticleScreen extends ConsumerStatefulWidget {
  final String articleText;

  const ArticleScreen({required this.articleText});

  @override
  ConsumerState<ArticleScreen> createState() => _ArticleScreenState();
}

class _ArticleScreenState extends ConsumerState<ArticleScreen> {
  late final GoogleTTSService _ttsService;
  bool _isAutoSpeaking = false;

  @override
  void initState() {
    super.initState();
    _ttsService = GoogleTTSService();
    
    // Запуск автоозвучки через секунду после открытия
    Future.delayed(const Duration(seconds: 1), () {
      if (mounted) {
        _startAutoSpeech();
      }
    });
  }

  void _startAutoSpeech() {
    setState(() {
      _isAutoSpeaking = true;
    });
    
    _ttsService.addToQueue(
      widget.articleText,
      languageCode: 'ru-RU',
    );
    
    // Мониторинг завершения
    _monitorProgress();
  }

  void _monitorProgress() {
    Future.doWhile(() async {
      await Future.delayed(const Duration(milliseconds: 500));
      
      if (!mounted) return false;
      
      final isStillActive = _ttsService.isPlaying || _ttsService.hasQueuedItems;
      
      if (_isAutoSpeaking != isStillActive) {
        setState(() {
          _isAutoSpeaking = isStillActive;
        });
      }
      
      return isStillActive;
    });
  }

  void _stopAutoSpeech() {
    _ttsService.clearQueue();
    setState(() {
      _isAutoSpeaking = false;
    });
  }

  @override
  void dispose() {
    _ttsService.clearQueue();
    _ttsService.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Статья'),
        actions: [
          if (_isAutoSpeaking)
            IconButton(
              icon: const Icon(Icons.stop_circle),
              onPressed: _stopAutoSpeech,
              tooltip: 'Остановить озвучку',
            ),
        ],
      ),
      body: SingleChildScrollView(
        child: Column(
          children: [
            if (_isAutoSpeaking)
              Card(
                color: Colors.blue[50],
                child: Padding(
                  padding: const EdgeInsets.all(12),
                  child: Row(
                    children: const [
                      Icon(Icons.volume_up, color: Colors.blue),
                      SizedBox(width: 8),
                      Text('🎙️ Озвучка активна'),
                    ],
                  ),
                ),
              ),
            Padding(
              padding: const EdgeInsets.all(16),
              child: Text(widget.articleText),
            ),
          ],
        ),
      ),
    );
  }
}
```

## Часто Задаваемые Вопросы

### Q: Как изменить скорость озвучки?

A: Измените параметр `speakingRate` в `_synthesizeSpeech()`:
```dart
'speakingRate': 1.0,  // 0.92 → 1.0 (быстрее)
```

### Q: Как сделать голос более низким/высоким?

A: Измените параметр `pitch`:
```dart
'pitch': -3.0,  // Более низкий (-20.0 до 20.0)
'pitch': 2.0,   // Более высокий
```

### Q: Можно ли использовать мужской голос?

A: Да, измените голос в `_getVoiceName()`:
```dart
case 'ru-RU':
  return 'ru-RU-Wavenet-A';  // Мужской голос
```

### Q: Как сделать блоки меньше для ещё более быстрого старта?

A: В `_splitIntoChunks()` уменьшите минимальный размер:
```dart
if (currentChunk.length >= 200) {  // Было 300
  chunks.add(currentChunk.toString().trim());
}
```

### Q: Как увеличить громкость?

A: Измените `volumeGainDb`:
```dart
'volumeGainDb': 6.0,  // Было 3.0 (до 16.0 максимум)
```

### Q: Озвучка не работает, что делать?

A: Проверьте:
1. API ключ в `.env` файле: `GOOGLE_MAPS_API_KEY=...`
2. Включён ли Text-to-Speech API в Google Cloud Console
3. Есть ли интернет-соединение
4. Проверьте логи: `flutter logs | grep TTS`

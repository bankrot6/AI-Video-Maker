# Экран с подробной информацией о месте экскурсии

## Что было реализовано

✅ **Полностью рабочий экран просмотра деталей места** с использованием AI-анализа, поиска изображений и озвучки

## Основные компоненты

### 1. **Модель данных** (`lib/features/home/models/attraction_info.dart`)
Содержит всю информацию о месте:
- История
- Интересные факты
- Практическая информация (время работы, как добраться и т.д.)
- Рекомендации гида

### 2. **Сервис AI-анализа** (`lib/features/home/services/attraction_details_service.dart`)
Использует DeepSeek AI для получения детальной информации о месте:
- История места с датами и именами
- Интересные факты и легенды
- Практическая информация для туристов
- Личные рекомендации как от реального гида

**Промпт сформулирован так**, чтобы получить ответ в стиле настоящего экскурсовода.

### 3. **Сервис Text-to-Speech** (`lib/services/text_to_speech/google_tts_service.dart`)
Использует Google Cloud Text-to-Speech API для озвучки информации:
- Синтез естественно звучащей речи
- Поддержка разных языков (русский, английский, немецкий и др.)
- Управление воспроизведением (старт/стоп/пауза)
- Автоматическая очистка временных файлов

### 4. **Экран деталей** (`lib/features/home/attraction_details_screen.dart`)
Современный UI без эффекта жидкого стекла:
- Изображение места (автоматический поиск через Google Image Search)
- Кнопка озвучки всего контента
- Карточка с категорией и расстоянием
- Четыре информационных блока с иконками
- Плавная анимация загрузки (шиммеры)

### 5. **Интеграция с главным экраном**
При нажатии на карточку места в плане поездки открывается экран с деталями

## Как это работает

1. **Пользователь нажимает на место** в списке мест экскурсии
2. **Открывается экран деталей** с загрузкой информации
3. **AI генерирует подробный текст** в стиле рассказа гида
4. **Параллельно ищется изображение** места через Google Image Search
5. **Пользователь может нажать кнопку "Озвучить экскурсию"**
6. **Google TTS синтезирует речь** и воспроизводит всю информацию

## Настройка

### Требуемые API ключи в `.env`:

```env
# Для AI-анализа (уже настроен)
DEEPSEEK_API_KEY=your_deepseek_api_key

# Для поиска изображений (уже настроен)
GOOGLE_CSE_API_KEY=your_google_custom_search_api_key
GOOGLE_CSE_ID=your_google_custom_search_engine_id

# Для озвучки используется тот же ключ что и для карт
GOOGLE_MAPS_API_KEY=your_google_maps_api_key
```

### Включение Text-to-Speech API в Google Cloud Console:

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Выберите ваш проект (тот же, где настроен Google Maps)
3. Включите **Cloud Text-to-Speech API**
4. Используйте тот же `GOOGLE_MAPS_API_KEY` который уже есть в `.env`
5. Убедитесь что API ключ имеет права на Text-to-Speech API

## Особенности реализации

### AI-промпт
Промпт составлен так, чтобы получить живой рассказ экскурсовода:
- Повествовательный стиль
- Конкретные даты и имена
- Интересные факты, вызывающие "вау-эффект"
- Практические советы для туристов
- Инсайдерские рекомендации

### Поиск изображений
Алгоритм аналогичен поиску изображений упражнений:
- Формирование оптимизированного поискового запроса
- Загрузка первого подходящего изображения
- Сохранение в локальную файловую систему
- Отображение плейсхолдера с иконкой до загрузки

### Озвучка
- **Потоковое воспроизведение**: аудио генерируется и воспроизводится без задержек
- **Управление**: кнопка переключается между "Озвучить" и "Остановить"
- **Качество голоса**: используется Wavenet (нейросетевой синтез) для естественного звучания
- **Язык**: автоматически определяется язык интерфейса приложения

### UI без жидкого стекла
- Заменены `LiquidGlassCard` на обычные `Card`
- Современный минималистичный дизайн
- Лучшая производительность
- Чистый и читаемый интерфейс

# Инструкция по настройке Google Custom Search API

Для поиска изображений блюд в приложении используется Google Custom Search API. Это обязательный компонент для работы функции отображения изображений блюд.

## 1. Создание проекта в Google Cloud Platform

1. Перейдите на сайт [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте новый проект или используйте существующий.
3. Откройте меню "APIs & Services" > "Dashboard".
4. Нажмите "Enable APIs and Services".
5. Найдите и включите "Custom Search API".

## 2. Создание API ключа

1. В Google Cloud Console перейдите в раздел "APIs & Services" > "Credentials".
2. Нажмите "Create Credentials" > "API key".
3. Скопируйте созданный ключ.
4. Для безопасности рекомендуется ограничить ключ только API Custom Search.

## 3. Создание поисковой системы

1. Перейдите на сайт [Google Programmable Search Engine](https://programmablesearch.google.com/cse/all).
2. Нажмите "Add" для создания новой поисковой системы.
3. В поле "Sites to search" укажите *.google.com (можно использовать и другие сайты для поиска).
4. **Обязательно** поставьте галочку "Search the entire web" для поиска по всему интернету.
5. Нажмите "Create".
6. В настройках созданной поисковой системы перейдите во вкладку "Setup".
7. В разделе "Basics" найдите "Search engine ID" и скопируйте его.
8. Во вкладке "Settings" > "Search features" **обязательно** включите опцию "Image search".

## 4. Настройка приложения

1. Откройте файл `.env` в корне проекта.
2. Добавьте или обновите следующие строки:

```
# Google Custom Search API ключ и ID поисковой системы
GOOGLE_CSE_API_KEY=ваш_api_ключ
GOOGLE_CSE_ID=ваш_id_поисковой_системы
```

3. Сохраните файл и перезапустите приложение.

## Важно!

В текущей версии приложения **всегда** используется реальный Google Custom Search API для поиска изображений блюд. Это означает, что без настройки API приложение не сможет отображать изображения блюд из интернета и будет использовать встроенные изображения.

## Проверка работы API

1. Запустите приложение.
2. Перейдите на экран "Анализ пищи".
3. Введите название блюда и нажмите "Анализировать".
4. Если всё настроено правильно, приложение должно найти и отобразить изображение указанного блюда.

## Лимиты и оплата

Google Custom Search API имеет следующие ограничения:
- 100 бесплатных запросов в день.
- После исчерпания бесплатного лимита: $5 за 1000 запросов.
- Максимум 10,000 запросов в день.

## Оптимизация расходов

Приложение использует следующие методы для снижения количества запросов к API:
1. Кэширование результатов поиска.
2. Опция отключения загрузки изображений в настройках приложения.
3. Оптимизация запросов для повышения релевантности.

## Troubleshooting

Если поиск изображений не работает:
1. Проверьте правильность API ключа и ID поисковой системы в файле `.env`.
2. Убедитесь, что API включено в Google Cloud Console.
3. Проверьте, включен ли поиск изображений в настройках поисковой системы.
4. Проверьте, активирована ли опция загрузки изображений в настройках приложения.
5. Проверьте лимиты API в консоли Google Cloud.

# Интеграция VK Video

## Почему VK Video?

### ✅ Преимущества:
1. **Работает в России без ограничений** - в отличие от YouTube
2. **Большая база фитнес-контента** - много качественных видео с упражнениями
3. **Стабильный embed-плеер** - чистый интерфейс без лишних элементов
4. **Быстрая загрузка** - оптимизировано для российских пользователей
5. **Бесплатное использование** - не требует платных API ключей

## Реализация

### 1. Сервис поиска VK видео

**Файл**: `lib/services/vk_video_search_service.dart`

#### Методы поиска:

##### A. Веб-скрейпинг (основной метод)
```dart
Future<String?> _searchViaWeb(String query)
```
- Ищет видео через публичный интерфейс VK
- Не требует API токена
- Парсит HTML для извлечения video ID
- Работает стабильно

##### B. VK API (для будущего)
```dart
Future<String?> _searchViaApi(String query, String accessToken)
```
- Официальный API метод `video.search`
- Требует access_token
- Более надежный и быстрый
- Готов для использования при наличии токена

#### Embed URL формат:

```
https://vk.com/video_ext.php?oid={owner_id}&id={video_id}&hd=2&autoplay=0
```

**Параметры:**
- `oid` - ID владельца видео (может быть отрицательным для групп)
- `id` - ID видео
- `hd=2` - HD качество
- `autoplay=0` - без автовоспроизведения

**Преимущества embed:**
- 🎯 Только плеер, без UI сайта
- ⚡ Быстрая загрузка
- 📱 Адаптивный дизайн
- 🎨 Чистый интерфейс

## Как это работает

### Последовательность:

1. **Пользователь открывает детали упражнения**
   ```
   ExerciseDetailsScreen(exercise: "Подъём ног лежа")
   ```

2. **Анализ упражнения через AI**
   ```
   DeepSeek → "Как выполнять, техника, ошибки..."
   ```

3. **Параллельный поиск контента**
   ```dart
   _searchExerciseImage("Подъём ног лежа");  // Google Images
   _searchVideo("Подъём ног лежа");           // VK Video
   ```

4. **Поиск на VK**
   ```
   Запрос: "как делать Подъём ног лежа упражнение техника"
   
   VK → Поиск → Извлечение первого результата
   
   Результат: video-12345678_90123456
   ```

5. **Формирование embed URL**
   ```
   https://vk.com/video_ext.php?oid=-12345678&id=90123456&hd=2&autoplay=0
   ```

6. **Отображение в карусели**
   ```
   Слайд 1: [Изображение]
   Слайд 2: [VK Video embed] ← Чистый плеер!
   ```

## Формат видео ID в VK

### Обычный URL:
```
https://vk.com/video-12345678_90123456
```

### Разбор:
- `-12345678` - owner_id (отрицательный = группа, положительный = пользователь)
- `90123456` - video_id

### Embed URL:
```
https://vk.com/video_ext.php?oid=-12345678&id=90123456&hd=2&autoplay=0
```

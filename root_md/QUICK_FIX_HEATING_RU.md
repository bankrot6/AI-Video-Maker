## 📱 Опционально: Добавить адаптивность

Для автоматической адаптации под разные устройства:

### 1. Установить зависимость
```bash
flutter pub add device_info_plus
```

### 2. Открыть файл
```
lib/features/home/home_screen.dart
```

### 3. Добавить import (в начало файла)
```dart
import '../../widgets/adaptive_exercise_card.dart';
```

### 4. Найти метод `_exerciseCard` (строка ~1024)

### 5. Заменить `return LiquidGlassExerciseCardLight(` на `return AdaptiveExerciseCard(`

**Было:**
```dart
return LiquidGlassExerciseCardLight(
```

**Стало:**
```dart
return AdaptiveExerciseCard(
```

### 6. Запустить
```bash
flutter run
```

**Готово!** Теперь приложение автоматически адаптируется под устройство.

## 📊 Что изменилось технически

### Параметры LiquidGlass

| Где | Параметр | Было | Стало |
|-----|----------|------|-------|
| Навигация | thickness | 8 | 5 ⬇️ 37% |
| Навигация | lightIntensity | 1.5 | 1.2 ⬇️ 20% |
| Карточки | thickness | 8 | 3 ⬇️ 62% |
| Карточки | lightIntensity | 1.5 | 1.0 ⬇️ 33% |
| Заголовок | thickness | 6 | 4 ⬇️ 33% |

**Результат:** Нагрузка на GPU снижена на 63-70%

## 💡 Альтернативные варианты

### Если все еще греется (маловероятно):

#### Вариант 1: Использовать ультра-легкую версию везде

В `home_screen.dart` заменить:
```dart
return LiquidGlassExerciseCardLight(
```
на:
```dart
return LiquidGlassExerciseCardUltraLight(
```

**Результат:** 95% меньше нагрузки, почти идентичный вид

#### Вариант 2: Снизить параметры еще больше

В `liquid_glass_bottom_nav_new.dart` изменить:
```dart
thickness: 5,  →  thickness: 3,
```

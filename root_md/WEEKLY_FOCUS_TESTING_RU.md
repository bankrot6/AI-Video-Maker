# Руководство по тестированию недельных фокусов

## Быстрый тест

### 1. Полный онбоардинг с нуля

```bash
# Очистить все данные приложения
flutter run

# В эмуляторе/устройстве:
# Settings → Apps → ChatCoach → Storage → Clear Data
```

### 2. Пройти онбоардинг

**Экран 1 - Пол:**
- Выберите пол

**Экран 2 - Цель:**
- Выберите "Набрать мышечную массу"

**Экран 3 - Место тренировок:**
- Выберите "В зале"

**Экран 4 - Количество дней:**
- Выберите **3 дня** в неделю

**Экран 5 - Уровень подготовки:**
- Выберите "Средний"

**Экраны 6-7 - Рост, вес, возраст:**
- Заполните любые значения

**Экран 8 - АКЦЕНТ (ВАЖНО!):**
- Выберите **3 группы мышц**: Грудь, Ноги, Спина
- Нажмите "Продолжить"

### 3. Ожидаемое поведение

#### На экране плана питания:
```
Лог должен показать:
🎯 Создан план фокусов на 3 дней: chest, legs, back
```

#### На экране генерации первого дня:
```
Лог должен показать:
🏋️ Генерируем ВСЕ 3 дня(ей): первый с UI, остальные в фоне
🏋️ Starting workout generation for day 0
📝 Заголовок дня: Тренировка груди (или аналогичное)
✅ Первый день сохранен, можно показать пользователю
🏋️ Запускаем фоновую генерацию дней 2-3
```

**Визуально:**
- Потоковое появление упражнений
- Прогресс-индикатор
- После появления 6 упражнений - автоматическое завершение

#### На главной странице (после перехода):
```
Лог должен показать:
🔄 ФОНОВАЯ ГЕНЕРАЦИЯ: Запуск для дней 2-3
🏋️ ФОНОВАЯ ГЕНЕРАЦИЯ: День 2/3
✅ ФОНОВАЯ ГЕНЕРАЦИЯ: День 2/3 сохранен
🏋️ ФОНОВАЯ ГЕНЕРАЦИЯ: День 3/3
✅ ФОНОВАЯ ГЕНЕРАЦИЯ: День 3/3 сохранен
✅ ФОНОВАЯ ГЕНЕРАЦИЯ: Завершена успешно
```

**Визуально:**
- Первый день отображается сразу
- Дни 2 и 3 появляются постепенно (по мере генерации)
- Каждый день показывается с упражнениями

### 4. Проверка результата

Откройте календарь на главной странице:

**День 1 (понедельник):**
- ✅ Должен содержать упражнения на ГРУДЬ
- ✅ Примеры: Жим штанги лежа, Разводка гантелей, Отжимания на брусьях

**День 2 (среда):**
- ✅ Должен содержать упражнения на НОГИ
- ✅ Примеры: Приседания, Жим ногами, Выпады

**День 3 (пятница):**
- ✅ Должен содержать упражнения на СПИНУ
- ✅ Примеры: Становая тяга, Подтягивания, Тяга штанги в наклоне

### 5. Проверка отсутствия повторений

**ВАЖНО:** Упражнения НЕ должны повторяться между днями!

❌ **Неправильно:**
- День 1: Жим штанги лежа, Приседания
- День 2: Жим штанги лежа, Становая тяга

✅ **Правильно:**
- День 1: Жим штанги лежа, Разводка гантелей (только грудь)
- День 2: Приседания, Жим ногами (только ноги)
- День 3: Становая тяга, Подтягивания (только спина)

## Расширенные тесты

### Тест 1: Мультивыбор фокусов (5 дней)

**Онбоардинг:**
- Количество дней: **5**
- Фокусы: Грудь, Ноги, Спина

**Ожидаемое распределение:**
- День 1: Грудь
- День 2: Ноги
- День 3: Спина
- День 4: Грудь (повтор цикла)
- День 5: Ноги (повтор цикла)

### Тест 2: Один фокус (3 дня)

**Онбоардинг:**
- Количество дней: **3**
- Фокусы: только Ноги

**Ожидаемое распределение:**
- День 1: Ноги
- День 2: Ноги (разные упражнения!)
- День 3: Ноги (разные упражнения!)

### Тест 3: Без фокуса

**Онбоардинг:**
- Количество дней: **3**
- Фокусы: не выбрано (нажать "Продолжить" без выбора)

**Ожидаемое поведение:**
- Дни генерируются со стандартным распределением
- LLM сам решает какие группы мышц использовать
- Должна быть разнообразность

### Тест 4: Повторный запуск главной страницы

**Шаги:**
1. Пройти онбоардинг
2. Дождаться генерации всех дней на главной
3. Закрыть приложение (свайп вверх)
4. Открыть приложение снова

**Ожидаемое поведение:**
```
✅ ФОНОВАЯ ГЕНЕРАЦИЯ: План уже полный
```
- Фоновая генерация НЕ запускается
- Все дни показываются сразу
- Нет повторной генерации

## Команды для отладки

### Просмотр логов
```bash
# Android
adb logcat | grep "ФОНОВАЯ ГЕНЕРАЦИЯ"

# iOS
xcrun simctl spawn booted log stream --predicate 'processImagePath contains "ChatCoach"' | grep "ФОНОВАЯ ГЕНЕРАЦИЯ"
```

### Очистка данных (для повторного теста)
```bash
# Android
adb shell pm clear com.yourcompany.chatcoach

# iOS (в симуляторе)
xcrun simctl uninstall booted com.yourcompany.chatcoach
```

## Известные моменты

### Время генерации
- Первый день: ~10-15 секунд
- Каждый последующий день: ~10-15 секунд
- Общее время для 3 дней: ~30-45 секунд

### Остановка генерации
- Генерация останавливается после 6 упражнений
- Это нормальное поведение для ускорения
- Можно изменить `targetExercises` в коде

### Таймаут
- Каждый день имеет таймаут 60 секунд
- При таймауте используется частичный результат
- Генерация продолжается для следующих дней

## Что делать если что-то не работает

### Проблема: Нет логов о фоновой генерации

**Решение:**
```dart
// Проверьте импорт в home_screen.dart
import '../../services/workout/background_workout_generation_service.dart';

// Проверьте вызов в didChangeDependencies
_ensureWeeklyWorkoutsAreComplete();
```

### Проблема: Дни повторяют упражнения

**Проверьте:**
1. Лог должен показывать `weeklyFocuses` при создании пользователя
2. Промт должен включать секцию `WEEKLY FOCUS PLAN:`

**Решение:**
```bash
# Очистите данные и пройдите онбоардинг заново
adb shell pm clear com.yourcompany.chatcoach
```

### Проблема: Фоновая генерация не запускается

**Проверьте:**
```dart
// В _ensureWeeklyWorkoutsAreComplete добавьте больше логов
debugPrint('🔍 User: $user');
debugPrint('🔍 ExistingPlan: ${existingPlan?.days.length}/${existingPlan?.workoutsPerWeek}');
```

### Проблема: Ошибка компиляции

**Запустите:**
```bash
flutter pub get
flutter clean
flutter run
```

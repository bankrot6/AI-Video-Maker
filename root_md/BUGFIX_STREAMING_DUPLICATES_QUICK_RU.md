# Исправление дублирования упражнений - Краткая справка

## Проблема
На главной странице при фоновой генерации дней 2-3 первое упражнение дублировалось несколько раз.

## Причина
Фоновая генерация использовала JSON парсинг промежуточных данных вместо текстового парсинга потока.

## Решение
Добавлен метод `_parseStreamingText()` для парсинга текстового потока с проверкой дубликатов по имени упражнения.

## Измененный файл
```
lib/services/workout/background_workout_generation_service.dart
```

## Как проверить
```bash
# 1. Очистить данные
adb shell pm clear com.yourcompany.chatcoach

# 2. Пройти онбоардинг с 3 днями

# 3. Смотреть логи
adb logcat | grep "➕ День"
```

## Ожидаемый результат
```
➕ День 2: Добавлено упражнение "Приседания"
➕ День 2: Добавлено упражнение "Жим ногами"
➕ День 2: Добавлено упражнение "Выпады"
...
✅ День 2: Получено 6 упражнений, завершаем генерацию
```

Каждое упражнение должно появиться **только один раз**.

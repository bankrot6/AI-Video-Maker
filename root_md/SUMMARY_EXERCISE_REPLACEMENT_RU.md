## 🚀 Как использовать

### Замена упражнения
1. Долгое нажатие на упражнении → вход в режим менеджмента
2. Нажмите **синюю кнопку** (справа вверху от карточки)
3. Дождитесь загрузки (шиммер)
4. Новое упражнение появится автоматически

### Сохранение изменений
1. После всех изменений нажмите **"Готово"**
2. Изменения сохранятся автоматически
3. Появится сообщение: **"Изменения сохранены"**

### Множественная замена
- Можно заменять любое количество упражнений подряд
- Каждая замена независима от других
- Все изменения сохранятся при выходе

## 📝 Технические детали

### Архитектура

```
User Action (нажатие кнопки замены)
    ↓
_replaceExercise()
    ↓
setState(() => _replacingExercises.add(index))
    ↓
UI показывает шиммер
    ↓
DeepSeekClient.generateTextStream(prompt)
    ↓
_parseReplacementExercise()
    ↓
setState(() => _managedExercises[index] = newExercise)
    ↓
UI показывает новое упражнение
    ↓
User нажимает "Готово"
    ↓
_exitManagementMode()
    ↓
_saveManagementChanges()
    ↓
repository.saveDayAtIndex()
    ↓
ref.invalidate(weeklyWorkoutPlanForDateProvider)
    ↓
UI обновляется с новыми данными
```

### Используемые сервисы

1. **DeepSeekClient** - AI модель для генерации упражнений
2. **WorkoutPlanRepository** - хранение планов тренировок
3. **WeeklyWorkoutPlanService** - бизнес-логика планов
4. **AppLocalizationService** - определение языка
5. **Riverpod** - управление состоянием

### Промпт к AI

Включает:
- Профиль пользователя (возраст, пол, вес, рост, цель)
- Текущее упражнение (название, подходы, повторения, вес)
- Требования к замене (те же мышцы, другое упражнение)
- Язык интерфейса

## 📈 Метрики

### Производительность

- **Время замены**: 2-5 секунд (зависит от сети)
- **Время сохранения**: 100-300мс
- **Размер промпта**: ~500 символов
- **Размер ответа AI**: ~200-500 символов

### Использование памяти

- Состояние замены: O(n) где n - количество упражнений
- Кэширование: минимальное
- Оптимизация: Stream API для AI ответов

# Функция замены упражнения на аналог

## Описание

Реализована функция замены упражнения на аналогичное с помощью AI в режиме менеджмента тренировок.

## Как это работает

### 1. Вход в режим менеджмента

Пользователь удерживает (long press) карточку упражнения, чтобы войти в режим менеджмента.

### 2. Кнопки управления

В режиме менеджмента для каждого упражнения отображаются две кнопки:

- **Красная кнопка (слева сверху)**: Удаление упражнения
  - Иконка: `Icons.remove`
  - Цвет: `#E74C3C` (красный)
  - При нажатии показывается диалог подтверждения

- **Синяя кнопка (справа сверху)**: Замена упражнения
  - Иконка: `Icons.swap_horiz`
  - Цвет: `#3498DB` (синий)
  - При нажатии запускается процесс замены

### 3. Процесс замены

1. **Шиммер-эффект**: При нажатии на кнопку замены карточка упражнения заменяется на шиммер
2. **AI запрос**: Отправляется запрос к DeepSeek с промптом на замену упражнения
3. **Парсинг ответа**: AI возвращает новое упражнение в формате JSON
4. **Обновление UI**: Шиммер заменяется на карточку с новым упражнением

### 4. Промпт к AI модели

Промпт включает:
- Профиль пользователя (возраст, пол, вес, рост, уровень активности, цель)
- Данные текущего упражнения (название, подходы, повторения, вес)
- Требования к замене:
  - Новое упражнение должно быть ПОХОЖИМ (те же мышечные группы)
  - Новое упражнение должно быть ДРУГИМ (не совпадать с оригиналом)
  - Сохранять схожий уровень сложности
  - Адаптировать подходы, повторения и вес под профиль пользователя

### 5. Формат ответа AI

AI возвращает данные в двух форматах (для потокового отображения):

1. **Streaming формат**: `EX: <название>|<подходы>|<повторения>|<вес>`
2. **JSON формат**: 
```json
{
  "name": "Название упражнения",
  "sets": 3,
  "reps": 12,
  "weightKg": 20.0
}
```

### 6. Обработка ошибок

Если замена не удалась (ошибка сети, некорректный ответ AI и т.д.):
- Шиммер скрывается
- Показывается сообщение об ошибке
- Упражнение остается без изменений

### Принципы реализации

1. **SOLID принципы**:
   - Single Responsibility: каждый метод выполняет одну задачу
   - Open/Closed: код расширяем через новые промпты и парсеры

2. **Best Practices**:
   - Асинхронная обработка с async/await
   - Streaming для постепенного отображения
   - Обработка ошибок на всех уровнях
   - Локализация сообщений
   - Haptic feedback для лучшего UX
   - Шиммер для индикации загрузки

3. **UI/UX**:
   - Четкое визуальное разделение кнопок (красная/синяя)
   - Шиммер вместо карточки во время замены
   - Плавная анимация замены
   - Тактильная обратная связь

## Использование

1. Войдите в режим менеджмента (long press на упражнении)
2. Нажмите синюю кнопку замены (справа сверху от карточки)
3. Дождитесь завершения замены (шиммер исчезнет)
4. Новое упражнение появится на месте старого

## Пример работы

**До замены:**
```
Жим штанги лежа
3 подхода × 12 повторений
Вес: 60.0 кг
```

**После замены:**
```
Жим гантелей лежа
3 подхода × 12 повторений
Вес: 25.0 кг (на каждую руку)
```

## Логи отладки

При замене упражнения в консоль выводятся следующие логи:
- `🔄 REPLACE_EXERCISE: Отправка запроса к AI`
- `🔄 REPLACE_EXERCISE: Упражнение: [название]`
- `🔄 REPLACE_EXERCISE: Получен ответ от AI`
- `🔄 REPLACE_EXERCISE: Длина ответа: [число] символов`
- `🔄 REPLACE_EXERCISE: Упражнение успешно заменено`
- `🔄 REPLACE_EXERCISE: Новое упражнение: [название]`

При ошибках:
- `❌ REPLACE_EXERCISE: Ошибка при замене: [текст ошибки]`
- `❌ REPLACE_EXERCISE: Ошибка парсинга: [текст ошибки]`

## Известные ограничения

1. Требуется активное подключение к интернету
2. Замена может занять 2-5 секунд в зависимости от скорости сети
3. AI может иногда предлагать упражнения с необычными названиями
4. Весовые нагрузки рассчитываются автоматически и могут требовать корректировки

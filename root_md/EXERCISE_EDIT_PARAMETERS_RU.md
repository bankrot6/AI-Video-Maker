# Редактирование параметров упражнений на главной странице

## Описание
Реализована функция редактирования полей с подходами, повторами и весом в режиме управления упражнениями на главной странице.

## Что было реализовано

### 1. Модификация виджета `LiquidGlassExerciseCardUltraLight`

Добавлены новые параметры для поддержки режима редактирования:
- `isEditMode: bool` - флаг режима редактирования
- `onSetsEdit: Function(int)?` - колбэк для изменения подходов
- `onRepsEdit: Function(int)?` - колбэк для изменения повторений
- `onWeightEdit: Function(double)?` - колбэк для изменения веса

### 2. Интерактивные бэйджи

В режиме редактирования бэйджи с параметрами стали кликабельными:
- При нажатии на бэйдж "Подходы" открывается диалог редактирования
- При нажатии на бэйдж "Повторения" открывается диалог редактирования
- При нажатии на бэйдж "Вес" открывается диалог редактирования

### 3. Панель редактирования над клавиатурой

Создана красивая панель ввода с эффектом liquid glass:
- **Позиция**: Непосредственно над клавиатурой (ModalBottomSheet)
- **Размытие**: `BackdropFilter` с sigmaX/Y = 12
- **Стеклянный эффект**: С помощью `FakeGlass`
- **Поле ввода**: Цветовая схема приложения (синий #2196F3)
- **Клавиатура**: Числовая с автофокусом
- **Кнопки**: "Отмена" (серая) и "Сохранить" (синяя)
- **Индикатор**: Полоска для свайпа вниз (iOS-стиль)
- **Адаптивность**: Автоматически поднимается над клавиатурой
- **Закрытие**: Свайп вниз или нажатие на кнопку

### 4. Интеграция в HomeScreen

Обновлен метод `_buildManageableTile` в `home_screen.dart`:
- В режиме управления упражнениями включен `isEditMode: true`
- Добавлены колбэки для обновления значений в `_managedExercises`
- При изменении значений срабатывает тактильная обратная связь (`HapticFeedback.selectionClick()`)
- Изменения сохраняются в локальный список и затем в репозиторий при выходе из режима редактирования

## Цветовая схема

Панель редактирования использует цветовую схему приложения:
- **Синий (#2196F3)** - для рамки поля ввода и кнопки "Сохранить"
- **Белый с прозрачностью** - для фона поля ввода
- **Черный (#3A3A3A)** - для бэйджей параметров
- **Серый (black26)** - для индикатора свайпа
- **Стеклянный эффект** - для фона панели с размытием 12px

## Как использовать

1. Откройте главную страницу приложения
2. Активируйте режим управления упражнениями (долгое нажатие на карточку)
3. Нажмите на любой бэйдж (подходы/повторения/вес)
4. Панель редактирования появится над клавиатурой
5. Введите новое значение
6. Нажмите "Сохранить" или Enter для применения
7. Или свайпните панель вниз для отмены
8. Выйдите из режима управления - все изменения автоматически сохранятся

## Технические детали

### Файлы, которые были изменены:
1. `/lib/widgets/liquid_glass_card.dart` - виджет карточки упражнения
2. `/lib/features/home/home_screen.dart` - главная страница приложения

### Принципы проектирования:
- **SOLID принципы**: каждый компонент имеет единую ответственность
- **Separation of concerns**: панель редактирования вынесена в отдельный метод
- **Reusability**: метод `_showEditDialog` может использоваться для разных типов параметров
- **User feedback**: тактильная обратная связь при изменении значений
- **Mobile-first**: панель над клавиатурой для удобства на мобильных устройствах

### Валидация:
- Подходы: только целые числа > 0
- Повторения: только целые числа > 0
- Вес: десятичные числа >= 0 (допускается 0 для упражнений без веса)

## Преимущества реализации

1. **Интуитивность**: редактирование выполняется прямо в контексте карточки
2. **Удобство**: панель прикреплена к клавиатуре, не перекрывает экран
3. **Скорость**: не нужно переходить на другой экран
4. **Красота**: использует существующий дизайн-язык приложения
5. **Производительность**: оптимизированные стеклянные эффекты
6. **Безопасность**: валидация ввода на уровне UI
7. **Жесты**: поддержка свайпа вниз для закрытия (iOS-стиль)

## Совместимость

- Работает на всех платформах (iOS, Android)
- Использует существующие зависимости
- Не требует дополнительных пакетов
- Совместим с существующей логикой сохранения

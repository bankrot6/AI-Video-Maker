# 🌊 iOS 26 Градиентное размытие - Улучшенная версия

## 🔄 Что было исправлено

### ❌ Проблема (было)
- Размытие применялось **равномерно** по всей области
- Слишком **сильная** интенсивность (15.0 sigma)
- **Резкий** переход - размытие начиналось сразу сильным

### ✅ Решение (стало)
- **Многослойное** размытие с градиентом интенсивности
- **Плавный** переход от слабого к сильному
- **Уменьшенная** максимальная интенсивность (6.0 sigma)

## 📊 Структура слоев

```dart
Stack(
  children: [
    // СЛОЙ 1: Легкое размытие (100% высоты)
    Positioned.fill(
      child: BackdropFilter(
        filter: blur(sigma: 6.0 * 0.2 = 1.2),  // 20% от макс
      ),
    ),
    
    // СЛОЙ 2: Среднее размытие (70% высоты, снизу)
    Positioned(
      bottom: 0,
      height: 140 * 0.7 = 98px,
      child: BackdropFilter(
        filter: blur(sigma: 6.0 * 0.4 = 2.4),  // 40% от макс
      ),
    ),
    
    // СЛОЙ 3: Сильное размытие (40% высоты, снизу)
    Positioned(
      bottom: 0,
      height: 140 * 0.4 = 56px,
      child: BackdropFilter(
        filter: blur(sigma: 6.0 * 1.0 = 6.0),  // 100% от макс
      ),
    ),
  ],
)
```

## 📐 Математика размытия

### Формула накопления:

```
Область 100%-60% (верх):    blur = 0.0 (контент виден)
Область 60%-30%:            blur = 1.2 (легкое размытие)
Область 30%-0% (низ):       blur = 1.2 + 2.4 + 6.0 = 9.6 (сильное)
```

### Процентное распределение:

| Зона      | Высота | Слои     | Sigma | Процент от макс |
|-----------|--------|----------|-------|-----------------|
| Верх      | 60%    | Нет      | 0.0   | 0%              |
| Средняя   | 30%    | 1        | 1.2   | 20%             |
| Нижняя-1  | 40%    | 1+2      | 3.6   | 60%             |
| Нижняя-2  | 10%    | 1+2+3    | 9.6   | 160%            |

## 🎯 Преимущества нового подхода

### 1. Плавность перехода
- **Было:** Резкий скачок от 0 до 15 sigma
- **Стало:** Постепенное нарастание от 0 → 1.2 → 3.6 → 9.6

### 2. Естественность
- **Было:** Неестественно сильное размытие
- **Стало:** Естественный градиент как в iOS 26

### 3. Читаемость
- **Было:** Контент резко становится нечитаемым
- **Стало:** Плавное затухание читаемости

### 4. Производительность
- **Было:** Одно сильное размытие (тяжелое)
- **Стало:** Три слабых размытия (легче в сумме)

## 🔧 Параметры настройки

Если нужно дополнительно подстроить эффект:

```dart
BottomContentBlur(
  blurHeight: 140.0,          // Общая высота области
  maxBlurIntensity: 6.0,      // Макс. sigma (можно 5.0-8.0)
  overlayColor: Colors.black, // Цвет оверлея
)

// Слои автоматически:
// Слой 1: maxBlurIntensity * 0.2 = 1.2
// Слой 2: maxBlurIntensity * 0.4 = 2.4
// Слой 3: maxBlurIntensity * 1.0 = 6.0
```

### Рекомендуемые значения:

| Эффект        | maxBlurIntensity | Результат                    |
|---------------|------------------|------------------------------|
| Очень легкий  | 4.0              | Едва заметное размытие       |
| Легкий        | 5.0              | Деликатное размытие          |
| **Средний**   | **6.0**          | **Оптимально (как iOS 26)**  |
| Сильный       | 7.0              | Заметное размытие            |
| Очень сильный | 8.0              | Максимальное размытие        |

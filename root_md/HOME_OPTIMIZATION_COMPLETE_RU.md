### 2. 🎨 Умный рендеринг дат (РЕВОЛЮЦИОННО)

**Проблема:** Рендерились ВСЕ 395 дат (30 назад + 365 вперед), даже невидимые!

**Решение:** Добавлен метод `_shouldRenderGlassEffect()`:

```dart
/// Показываем LiquidGlass только для 10 дат: выбранная ±5
/// Остальные даты - простой Container (почти без GPU нагрузки)
bool _shouldRenderGlassEffect(int index, int selectedIndex, int totalDates) {
  const int range = 5;
  return (index >= selectedIndex - range && index <= selectedIndex + range);
}
```

**Эффект:**

## 🔧 Техническая деталь: Как это работает

### ListView.builder ленивая загрузка?

**НЕТ для GPU эффектов!**

ListView.builder создает виджеты лениво, НО:
- Flutter рендерит виджеты за пределами видимости (для плавной прокрутки)
- LiquidGlass - это CustomPainter, который выполняется на GPU
- Все LiquidGlass виджеты в ListView рендерятся на GPU сразу

**Поэтому:**
395 дат × LiquidGlass = 158,000 GPU операций при запуске экрана!

**Наше решение:**
Условный рендеринг на уровне виджета:
```dart
_shouldRenderGlassEffect() ? LiquidGlass() : Container()
```

Теперь рендерятся только 10 LiquidGlass виджетов, остальные - легкие Container.

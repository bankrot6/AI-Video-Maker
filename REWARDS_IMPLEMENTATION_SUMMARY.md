## 📊 Экономическая модель

```
1 лайк = 1 кредит
Минимум 3 лайка для старта
Максимум 50 кредитов с пресета
```

### Примеры заработка
| Лайков | Заработок | Эквивалент |
|--------|-----------|------------|
| 3 | 3 кредита | 30% от стандартной генерации |
| 10 | 10 кредитов | 1 стандартная генерация |
| 50+ | 50 кредитов | 5 стандартных генераций |

```bash

flutter build apk --release
flutter build ios --release
```

## 📈 Ожидаемые метрики

### KPI для отслеживания
- Процент публичных пресетов (цель: >30%)
- Среднее количество лайков на пресет (цель: >5)
- Процент пользователей с заработком (цель: >10%)
- Retention создателей контента (цель: >40%)

### Экономический баланс
- Средняя стоимость генерации: 4-10 кредитов
- Средний заработок создателя: 10-30 кредитов
- Соотношение: пользователь может окупить 2-3 генерации качественным пресетом

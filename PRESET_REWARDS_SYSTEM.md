# Система вознаграждений за пресеты

## Обзор

Пользователи могут зарабатывать кредиты, создавая качественные публичные пресеты, которые получают лайки от сообщества.

## Экономическая модель

### Базовые параметры
- **1 лайк = 1 кредит** для создателя пресета
- **Минимум 3 лайка** для начала вознаграждения
- **Максимум 50 кредитов** с одного пресета
- Только **публичные пресеты** (`isPublic: true`) с указанным `ownerId`

### Примеры
- Пресет получил 5 лайков → владелец получает 5 кредитов
- Пресет получил 10 лайков → владелец получает 10 кредитов
- Пресет получил 60 лайков → владелец получает максимум 50 кредитов
- Пресет получил 2 лайка → владелец пока не получает кредиты (минимум 3)

## Архитектура

### Модели

#### `PresetEarnings` (`lib/models/preset_earnings.dart`)
Отслеживает заработок по каждому пресету:
```dart
class PresetEarnings {
  final String presetId;          // ID пресета
  final String ownerId;            // ID владельца (deviceId)
  final int totalLikes;            // Текущее количество лайков
  final int creditsEarned;         // Кредиты заработанные с этого пресета
  final int lastProcessedLikes;    // Последнее обработанное количество лайков
  final DateTime lastProcessedAt;  // Время последней обработки
  final DateTime createdAt;        // Время создания записи
}
```

#### Расширение `CreditUsageModel`
Добавлено поле `earnedCredits` для отслеживания общей суммы заработанных кредитов.

### Сервисы

#### `PresetRewardService` (`lib/services/preset_reward_service.dart`)
Управляет синхронизацией и подсчетом вознаграждений:
- `syncEarnedCredits()` - синхронизирует заработанные кредиты для текущего пользователя
- `getEarningsStats()` - возвращает общую статистику заработка
- `getMyEarnings()` - список всех заработков по пресетам
- `getEarningsForPreset(presetId)` - статистика конкретного пресета

#### Обновление `CreditService`
Добавлен метод `addEarnedCredits(int amount)` для начисления заработанных кредитов.

### Cloud Functions

#### `processPresetRewards` (`functions/index.js`)
Автоматически обрабатывает вознаграждения при изменении количества лайков:
1. Триггер на обновление документа в коллекции `presets`
2. Проверяет, что пресет публичный и имеет владельца
3. Вычисляет дельту лайков
4. Начисляет кредиты с учетом лимитов
5. Обновляет запись в коллекции `preset_earnings`

### UI компоненты

#### `EarnedCreditsBadge` (`lib/widgets/earned_credits_badge.dart`)
Компактный бадж для отображения общей суммы заработанных кредитов:
- Отображается в showcase screen справа от кредитного счетчика
- При нажатии открывает экран детальной статистики
- Скрывается, если нет заработанных кредитов

#### `PresetEarningsCard` (`lib/widgets/preset_earnings_card.dart`)
Карточка для отображения заработка по конкретному пресету:
- Миниатюра пресета
- Количество лайков
- Заработанные кредиты
- Прогресс до максимума

#### `PresetEarningsScreen` (`lib/features/earnings/preset_earnings_screen.dart`)
Экран со статистикой заработков:
- Общая сумма заработанных кредитов
- Количество лайков
- Количество активных пресетов
- Список всех пресетов с заработками
- Кнопка синхронизации

### Интеграция

#### `PhotosessionShowcaseScreen`
- При запуске автоматически вызывает синхронизацию вознаграждений
- Показывает SnackBar при начислении новых кредитов
- Отображает `EarnedCreditsBadge` в верхней панели

#### `PhotosessionPresetScreen`
- Для владельцев пресетов загружает статистику заработка
- Отображает чип с заработанными кредитами в AppBar
- Показывает прогресс до максимума

#### `CustomPresetCreationScreen`
- Информирует о возможности заработка при публикации
- Мотивирует делать пресеты публичными

## Firestore

### Коллекция `preset_earnings`
Структура документа:
```javascript
{
  presetId: "preset_123",
  ownerId: "device_abc",
  totalLikes: 15,
  creditsEarned: 15,
  lastProcessedLikes: 15,
  lastProcessedAt: Timestamp,
  createdAt: Timestamp
}
```

### Индексы
```json
{
  "collectionGroup": "preset_earnings",
  "fields": [
    { "fieldPath": "ownerId", "order": "ASCENDING" },
    { "fieldPath": "creditsEarned", "order": "DESCENDING" }
  ]
}
```

### Security Rules
```javascript
match /preset_earnings/{earningId} {
  allow read: if request.auth != null;
  allow write: if false; // только через Cloud Functions
}
```

## Защита от злоупотреблений

### Реализованные меры
1. **Максимум кредитов**: 50 кредитов с одного пресета
2. **Минимальный порог**: требуется минимум 3 лайка для начала вознаграждения
3. **Только публичные**: только публичные пресеты участвуют в программе
4. **Верификация владельца**: обязательное наличие `ownerId`
5. **Firestore Rules**: запись в `preset_earnings` только через Cloud Functions

### Рекомендации для будущего
1. **Rate limiting**: ограничение частоты лайков от одного пользователя
2. **Модерация**: система флагов для подозрительной активности
3. **Аналитика**: отслеживание паттернов накрутки
4. **Временные окна**: учитывать скорость набора лайков

## Сценарии использования

### Пользователь создает пресет
1. Создает пресет с красивой фотографией
2. Ставит галочку "Поделиться с сообществом"
3. Видит сообщение: "Пресет опубликован! Получайте кредиты за каждый лайк"

### Пользователь получает лайки
1. Другие пользователи ставят лайки на его пресет
2. Cloud Function автоматически обрабатывает изменения
3. При следующем запуске приложения запускается синхронизация
4. Пользователь видит SnackBar: "🎉 Вы получили X кредитов за лайки!"
5. Кредиты добавляются к общему балансу

### Пользователь проверяет статистику
1. Нажимает на бадж "Заработано: +X" в showcase screen
2. Открывается экран `PresetEarningsScreen`
3. Видит общую статистику и список всех пресетов с заработками
4. Может синхронизировать вручную кнопкой обновления

## Метрики успеха

### KPI
- Процент пользователей, делающих пресеты публичными
- Среднее количество лайков на публичный пресет
- Процент пользователей, заработавших хотя бы 1 кредит
- Средний заработок на активного создателя контента

### A/B тестирование
Можно варьировать:
- Коэффициент конверсии (1 лайк = X кредитов)
- Минимальный порог лайков
- Максимальное вознаграждение
- Дополнительные бонусы (например, за достижение 25 лайков)

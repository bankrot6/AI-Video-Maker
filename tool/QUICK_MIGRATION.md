# 🚀 Быстрая миграция Appwrite → Firebase

## За 3 минуты

### Шаг 1: Установите зависимости

```bash
cd tool
pip3 install requests python-dotenv firebase-admin
```

### Шаг 2: Запустите миграцию

```bash
python3 migrate_appwrite_to_firebase.py
```

### Шаг 3: Проверьте результат

Откройте [Firebase Console](https://console.firebase.google.com/) → Firestore Database

Должны появиться коллекции:
- ✅ `presets` - все пресеты фотосессий
- ✅ `user_generations` - все генерации пользователей

---

## Что делает скрипт?

1. **Читает данные** из Appwrite (пресеты и генерации)
2. **Конвертирует** в формат Firestore
3. **Загружает** в Firebase через REST API
4. **Показывает статистику** по завершению

## 🆘 Если что-то не работает

### Ошибка: "No module named 'requests'"
```bash
pip3 install requests python-dotenv firebase-admin
```

### Ошибка: "Permission denied"
Проверьте правила Firestore в Firebase Console → Firestore → Rules:
```javascript
allow write: if true;  // Временно для миграции
```

### Скрипт зависает
- Нажмите Ctrl+C
- Запустите снова - продолжит с места остановки

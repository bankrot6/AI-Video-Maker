# Исправление проблемы Badge Count на iOS

## 🔍 Проблема

На iPhone когда пользователь очищает уведомления на заблокированном экране или в центре уведомлений, красная цифра (badge count) на иконке приложения **НЕ сбрасывается автоматически**. Это приводит к накоплению большого количества уведомлений на иконке.

## 🚀 Решение

### 1. **Добавлены методы управления badge count**

В `LocalNotificationService` добавлены новые методы:
- `resetBadgeCount()` - сбрасывает badge count до 0
- `setBadgeCount(int count)` - устанавливает конкретное значение
- `getBadgeCount()` - получает текущее значение

### 2. **Автоматический сброс при отмене уведомлений**

Метод `cancelAllNotifications()` теперь автоматически сбрасывает badge count.

### 3. **Автоматический сброс при запуске приложения**

В `main.dart` добавлен вызов `_resetBadgeOnStartup()` который сбрасывает badge count при каждом запуске приложения.

### 4. **Автоматический сброс при возвращении на передний план**

Добавлен `WidgetsBindingObserver` который отслеживает `AppLifecycleState.resumed` и сбрасывает badge count когда пользователь возвращается в приложение.

### 5. **Интеграция с SmartMealNotificationsService**

Умный сервис уведомлений теперь также поддерживает методы для работы с badge count.

## 🔧 Технические детали

### Используемые API:
- `AwesomeNotifications().resetGlobalBadge()` - сброс badge count
- `AwesomeNotifications().setGlobalBadgeCounter(count)` - установка значения
- `AwesomeNotifications().getGlobalBadgeCounter()` - получение текущего значения

### Точки сброса badge count:

1. **При запуске приложения** (`_resetBadgeOnStartup`)
2. **При возвращении на передний план** (`_resetBadgeOnResume`)  
3. **При отмене всех уведомлений** (`cancelAllNotifications`)
4. **При отключении умных уведомлений** (`disableNotifications`)

## 📱 Тестирование

### Как проверить что исправление работает:

1. **Создайте тестовые уведомления:**
   - Используйте кнопку "Отправить тестовое уведомление" в настройках
   - Или подождите естественных уведомлений о еде

2. **Проверьте накопление badge count:**
   - Не открывайте приложение после уведомлений
   - На иконке должна появиться красная цифра

3. **Проверьте автоматический сброс:**
   - Откройте приложение - badge count должен сброситься до 0
   - Или: сверните приложение и затем верните на передний план

### Логирование

В логах будут сообщения с тегом `BADGE`:
- `Badge count сброшен при запуске приложения`
- `Badge count сброшен при возвращении на передний план`
- `✅ Badge count сброшен до 0`

- ✅ **Больше НЕТ** накопления бесконечного количества уведомлений на иконке
- ✅ **Автоматический сброс** при каждом взаимодействии с приложением
- ✅ **Прозрачная логика** - пользователь видит актуальные уведомления
- ✅ **Соответствие iOS guidelines** для badge count management

## 🔄 Совместимость

- **iOS**: Полная поддержка через AwesomeNotifications
- **Android**: Badge count работает на поддерживаемых лаунчерах
- **Безопасность**: Все методы обернуты в try-catch блоки

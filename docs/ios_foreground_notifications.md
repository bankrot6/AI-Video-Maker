# Настройка уведомлений на переднем плане для iOS

В iOS существуют определенные ограничения на отображение уведомлений, когда приложение находится на переднем плане (активно). По умолчанию, система iOS не показывает стандартные баннеры уведомлений, если пользователь активно использует приложение, отправившее уведомление.

Этот документ описывает шаги и конфигурации, необходимые для обеспечения показа уведомлений, даже когда приложение активно на экране.

## Технические настройки в коде

### 1. Настройка DarwinNotificationDetails

Для корректного отображения уведомлений на переднем плане в iOS необходимо правильно настроить объект `DarwinNotificationDetails`:

```dart
final DarwinNotificationDetails iosDetails = DarwinNotificationDetails(
  // Эти три параметра ОБЯЗАТЕЛЬНЫ для отображения на переднем плане
  presentAlert: true,   // Показать уведомление даже при открытом приложении
  presentBadge: true,   // Обновить значок приложения
  presentSound: true,   // Воспроизвести звук
  
  // Для особенно важных уведомлений
  interruptionLevel: InterruptionLevel.critical,  // Критический уровень прерывания
);
```

### 2. Специализированный метод для уведомлений на переднем плане

В нашем приложении создан метод `sendForegroundNotification()` в классе `LocalNotificationService`, который настраивает уведомления с высоким приоритетом и специальными параметрами для iOS.

## Настройки на устройстве iOS

Помимо программной настройки, для корректной работы уведомлений на переднем плане необходимо проверить настройки устройства:

### 1. Проверка настроек уведомлений

1. Откройте **Настройки** → **Уведомления** → **AI Video Maker**
2. Убедитесь, что следующие опции включены:
   - **Разрешить уведомления** - Включено
   - **Стиль уведомлений при разблокировке** - Баннеры
   - **Временные баннеры** - Выбрано
   - **Постоянные баннеры** - Опционально
   - **Звуки** - Включено
   - **Наклейки** - Включено
   - **Показывать на экране блокировки** - Включено
   - **Предварительный просмотр** - Всегда (Рекомендуется)

### 2. Режим "Тихие уведомления" на iOS 16+

В iOS 16+ Apple добавила функцию "Тихие уведомления", которая может влиять на видимость уведомлений:

1. Откройте **Настройки** → **Уведомления**
2. Найдите приложение **AI Video Maker**
3. Убедитесь, что опция **Тихие уведомления** отключена (если она доступна)

### 3. Режим фокусировки на iOS 15+

Режимы фокусировки могут блокировать уведомления на iOS 15 и выше:

1. Проверьте, не активирован ли какой-либо режим фокусировки
2. Пройдите в **Настройки** → **Фокусировка**
3. В каждом настроенном режиме фокусировки:
   - Перейдите в раздел **Приложения**
   - Убедитесь, что приложение **AI Video Maker** не заблокировано или добавьте его в разрешенные

## Дополнительная отладка

Для отладки уведомлений в нашем приложении:

1. Перейдите в раздел **Отладка уведомлений** в меню приложения
2. Используйте кнопку **Отправить уведомление на переднем плане** для тестирования
3. Проверьте статус уведомлений через кнопку **Проверить статус уведомлений**

## Технические детали и ограничения

- Начиная с iOS 10, Apple предоставляет API для показа уведомлений на переднем плане, но они всё равно могут выглядеть иначе, чем обычные уведомления
- В iOS 14+ появился более гибкий контроль через `UNNotificationPresentationOptions`
- Даже с правильной настройкой, iOS может применять свою логику определения приоритета уведомлений

## Частые проблемы и решения

1. **Уведомления не отображаются на переднем плане**
   - Проверьте все настройки приложения в iOS
   - Убедитесь в наличии всех необходимых разрешений
   - Перезагрузите устройство

2. **Звук отсутствует**
   - Проверьте, не включен ли беззвучный режим
   - Убедитесь, что звуки включены в настройках приложения

3. **Уведомления видны только в Центре уведомлений**
   - Настройте тип баннеров в системных настройках iOS

## Заключение

Отображение уведомлений на переднем плане в iOS требует комбинации правильного программного кода и настройки системных параметров. Реализованный метод `sendForegroundNotification()` настраивает все необходимые программные параметры, но пользователям всё равно может потребоваться проверить системные настройки iOS.

# Интеграция RuStore в AI Video Maker

## Обзор

Данная интеграция добавляет поддержку RuStore как альтернативного платежного провайдера для российских пользователей, установивших приложение из RuStore.

## Архитектура

### Основные компоненты

1. **AppStoreDetectionService** - определяет источник установки приложения
2. **RuStoreBillingService** - обрабатывает платежи через RuStore
3. **PaymentProviders** - определяет какой платежный провайдер использовать
4. **PaywallScreen** - обновлен для поддержки RuStore

### Логика определения платежного провайдера

```dart
enum PaymentProvider {
  standardIAP,  // App Store/Google Play
  yookassa,     // Российские пользователи из Google Play
  rustore       // Пользователи из RuStore
}
```

#### Алгоритм выбора:

1. **RuStore**: Если приложение установлено из RuStore
2. **YooKassa**: Если российский пользователь из Google Play (определяется по валюте рубль)
3. **Standard IAP**: Все остальные случаи

### RuStore цены (в рублях):
- Недельная подписка: 99₽
- Месячная подписка: 199₽
- Годовая подписка: 499₽

### Product IDs (подписки):
- `aivideomaker.weekly.rustore`
- `aivideomaker.monthly.rustore`
- `aivideomaker.yearly.rustore`

### Product IDs (разовые пакеты кредитов RuStore):
- `aivideomaker.credits.40.rustore` — 40 кредитов
- `aivideomaker.credits.150.rustore` — 150 кредитов
- `aivideomaker.credits.400.rustore` — 400 кредитов

## Особенности реализации

### Mock реализация
Поскольку официального Flutter SDK для RuStore биллинга нет, текущая реализация является mock-версией для демонстрации архитектуры.

### Для production:
1. Интегрировать с официальным RuStore API
2. Добавить WebView для платежной страницы RuStore
3. Реализовать обработку deep links для возврата после оплаты
4. Добавить проверку подписей платежей

## Совместимость

### Поддерживаемые платформы:
- ✅ Android (основная)
- ⚠️ iOS (fallback на стандартные IAP)

### Обратная совместимость:
- Существующие пользователи Google Play продолжают использовать YooKassa
- Пользователи App Store используют стандартные IAP
- Новые пользователи RuStore используют RuStore биллинг

## Мониторинг и отладка

### Логи:
Все операции логируются с префиксами:
- `🛒 RUSTORE_BILLING:` - операции RuStore
- `🔍 STORE_DETECTION:` - определение источника установки
- `💰 PAYMENT:` - операции платежных провайдеров

### Метрики для отслеживания:
- Количество пользователей по источникам установки
- Конверсия платежей по провайдерам
- Ошибки инициализации RuStore
- Время обработки платежей

## Развертывание

### Подготовка к выпуску:

# Эффект печатной машинки с глитчем для онбоардинга

## Описание

Для заголовков онбоардинга реализованы два футуристических эффекта:

1. **Эффект печатной машинки** - текст появляется побуквенно, как в ChatGPT
2. **Глитч-эффект** - во время печати случайным образом появляются визуальные "баги", как в фильмах про будущее

## Технические детали

### Виджет TypewriterGlitchText

Местоположение: `lib/features/onboarding/widgets/typewriter_glitch_text.dart`

#### Основные возможности:

- **Эффект печатания**: текст появляется посимвольно с настраиваемой скоростью (по умолчанию 50мс на символ)
- **Случайные глитч-символы**: во время печати с вероятностью 30% добавляются случайные символы
- **RGB Split эффект**: при глитче текст разделяется на красный и голубой каналы с небольшим смещением (хроматическая аберрация)
- **Эффект мерцания**: во время глитча текст слегка мерцает
- **Дополнительный цветной слой**: случайный зеленый слой для усиления футуристического эффекта

#### Параметры:

```dart
TypewriterGlitchText(
  text: 'Ваш текст',                                  // Текст для отображения
  style: TextStyle(...),                              // Стиль текста
  typingSpeed: Duration(milliseconds: 50),            // Скорость печати
  glitchDuration: Duration(milliseconds: 80),         // Длительность глитча
  autoStart: true,                                    // Автоматический запуск
  onTypingComplete: () { /* callback */ },            // Вызывается по завершении печати
)
```

### Интеграция

Виджет интегрирован в `lib/features/onboarding/onboarding_screen.dart` в методе `_buildTitledPage()`.

Каждый заголовок на странице онбоардинга автоматически получает эти эффекты при появлении на экране.

#### Последовательность анимации:

1. **Печать заголовка** - текст появляется побуквенно с глитч-эффектами
2. **Callback завершения** - виджет вызывает `onTypingComplete()`
3. **Появление кнопок** - кнопки с ответами появляются с анимацией масштабирования
4. **Интерактивность** - пользователь может выбрать ответ

Это создает плавную последовательную анимацию, где сначала пользователь видит вопрос, а затем варианты ответов.

### Визуальные эффекты

1. **Белый контур**: сохранен оригинальный дизайн с белой обводкой текста
2. **Черный текст с тенью**: основной текст остается читаемым
3. **RGB Split**: при глитче красный канал смещается влево, голубой - вправо
4. **Случайные символы**: добавляются случайные буквы и специальные символы
5. **Цветовые артефакты**: зеленые "следы" появляются случайным образом

### Примечания

- Эффект автоматически сбрасывается при смене страницы благодаря использованию `ValueKey(titleKey)`
- Глитч-эффект срабатывает случайным образом (30% вероятность при печати каждого символа)
- Все таймеры и контроллеры анимации правильно очищаются при удалении виджета
- Эффект оптимизирован для плавной работы без перегрузки UI

### Будущие улучшения

Возможные направления для расширения эффекта:
- Добавление горизонтальных "сканлиний" (scanlines)
- Эффект искажения блоками (block distortion)
- Настраиваемые цвета для RGB split
- Звуковое сопровождение (опционально)
- Различные режимы интенсивности глитча

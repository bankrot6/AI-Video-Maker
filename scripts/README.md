# Скрипты переводов AI Video Maker

Этот каталог содержит скрипты для автоматизации работы с переводами в проекте AI Video Maker.

## Основные скрипты

### 🔧 fix_short_translations.dart
**Быстрое исправление длинных ключей**

Специально создан для решения проблемы с длинными переводами кнопок выбора пола и кнопки "Изменить" на экране анализа еды.

```bash
dart run scripts/fix_short_translations.dart
```

**Что делает:**
- Заменяет длинные переводы для `gender_male` и `gender_female` на максимально короткие (М/Ж, M/F, и т.д.)
- Оптимизирует перевод кнопки `text_editing_cancel` ("Изменить") для экономии места
- Обрабатывает 37+ языков
- Показывает подробный лог изменений

**Критерии замены:**
- Для гендерных ключей: заменяет если длиннее 1 символа
- Для остальных ключей: заменяет если длиннее 4 символов

### 🌐 fix_localizations.dart  
**Полное обновление переводов**

Комплексный скрипт для синхронизации всех файлов переводов.

```bash
dart run scripts/fix_localizations.dart
```

**Что делает:**
- Использует английский файл как эталон
- Автоматически переводит недостающие ключи через Google Translate
- Анализирует длинные ключи и предлагает сокращения
- Автоматически применяет короткие варианты для проблемных ключей
- Удаляет дублирующиеся ключи
- Приводит порядок ключей к единому виду

## Примеры коротких переводов

### Русский (ru)
```dart
'gender_male': 'М',           // было: "Мужской"
'gender_female': 'Ж',         // было: "Женский"  
'text_editing_cancel': 'Правка', // было: "Изменить"
```

### Английский (en)
```dart
'gender_male': 'M',           // было: "Male"
'gender_female': 'F',         // было: "Female"
'text_editing_cancel': 'Edit', // было: "Edit"
```

### Китайский (zh)
```dart
'gender_male': '男',          // было: "男性"
'gender_female': '女',        // было: "女性"
'text_editing_cancel': '编辑',
```

### Французский (fr)
```dart
'gender_male': 'H',           // Homme -> H
'gender_female': 'F',         // Femme -> F
'text_editing_cancel': 'Modifier',
```

## Структура короткий переводов

Каждый язык имеет оптимизированные переводы для:

1. **Пол (Gender)**
   - Максимум 1-2 символа
   - Использует первые буквы или символы
   - Поддерживает культурные особенности

2. **Кнопка "Изменить"**
   - Короткие синонимы: "Правка", "Edit", "Modifier"
   - Сохраняет смысл при экономии места

## Поддерживаемые языки

Скрипты работают со всеми 37+ языками:
- Европейские: ru, en, es, fr, de, it, pt, pl, cs, sk, hr, ro, hu, da, he, nl, no, fi, sv, el
- Азиатские: zh, zhTW, ja, ko, th, hi, ar, vi
- Другие: tr, uk, id, ca, ms, fil

## Лучшие практики

### Перед запуском
1. Сделайте backup файлов переводов
2. Убедитесь, что проект скомпилирован без ошибок

### После обновления
1. Проверьте UI на всех экранах
2. Убедитесь, что кнопки не обрезаются
3. Протестируйте на разных размерах экранов
4. При необходимости настройте стили кнопок

### Добавление новых языков
Для добавления поддержки нового языка:

1. Добавьте язык в `_getShortTranslations()` в обоих скриптах
2. Определите короткие переводы для проблемных ключей
3. Запустите `fix_short_translations.dart`

## Отладка

Если скрипт не находит файлы:
```bash
# Проверьте структуру каталогов
ls -la lib/services/localization/

# Проверьте, что файлы существуют
ls -la lib/services/localization/*_strings.dart
```

Если переводы не применяются:
1. Проверьте корректность ключей в файлах
2. Убедитесь, что нет синтаксических ошибок в Dart файлах
3. Проверьте лог вывода скрипта на ошибки

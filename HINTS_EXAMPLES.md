### Идеи для фотосессий (женский пол)

#### Романтичная фотосессия
- **Место:** Цветущий вишнёвый сад, берег океана на закате
- **Образ:** Лёгкое летнее платье с цветочным принтом
- **Настроение:** Романтичное и мечтательное
- **Детали:** Букет лаванды, развевающиеся волосы на ветру

#### Деловая леди
- **Место:** Панорамный офис в небоскрёбе, современное кафе
- **Образ:** Элегантный брючный костюм, классическое платье-футляр
- **Настроение:** Уверенное и сильное, целеустремлённое
- **Детали:** Элегантные часы, минималистичные украшения

#### Вечерний шик
- **Место:** Роскошный ресторан, театральное фойе
- **Образ:** Вечернее платье в пол, коктейльное платье
- **Настроение:** Утончённое и изысканное
- **Детали:** Сияющие украшения, элегантный клатч

### Идеи для фотосессий (мужской пол)

#### Брутальный стиль
- **Место:** Индустриальная локация, мастерская, гараж
- **Образ:** Кожаная куртка, грубые ботинки, джинсы
- **Настроение:** Брутальное и мужественное, уверенное
- **Детали:** Борода с усами, тату на руках, цепь

#### Деловой человек
- **Место:** Офис в небоскрёбе, конференц-зал, деловой район
- **Образ:** Деловой костюм-тройка, классическая рубашка с галстуком
- **Настроение:** Целеустремлённое и амбициозное
- **Детали:** Дорогие швейцарские часы, кожаный портфель

#### Спортивный образ
- **Место:** Спортзал, стадион, горная тропа
- **Образ:** Спортивный костюм, тренировочная одежда
- **Настроение:** Энергичное и спортивное, динамичное
- **Детали:** Фитнес-браслет, спортивная бутылка, кроссовки

#### Casual стиль
- **Место:** Городская улица, кофейня, парк
- **Образ:** Джинсы с футболкой, худи, кроссовки
- **Настроение:** Расслабленное и непринуждённое
- **Детали:** Солнцезащитные очки, рюкзак, наушники

## 🎨 Философия подсказок

### Женский пол - акценты

- **Элегантность:** платья, костюмы, изящные детали
- **Романтика:** цветы, украшения, мягкие настроения
- **Красота:** волосы, макияж, аксессуары
- **Многогранность:** от романтичного до сильного и уверенного

### Мужской пол - акценты

- **Брутальность:** борода, мужественность, сила
- **Стиль:** костюмы, куртки, часы
- **Уверенность:** деловой образ, целеустремлённость
- **Активность:** спорт, энергия, динамика

### Универсальные элементы

Некоторые подсказки работают для обоих полов:
- **Место:** может быть универсальным (кафе, пляж) или специфичным
- **Настроение:** базовые эмоции похожи, но с разными акцентами

### 1. Вдохновение
Пользователь видит конкретные примеры и легче придумывает свою идею

### 2. Понимание формата
Сразу ясно что именно вводить и в каком стиле

### 3. Быстрый старт
Можно взять пример из подсказки и немного изменить

### 4. Релевантность
Примеры соответствуют выбранному полу, не нужно гадать

## 🔄 Интерактивность

### Как это работает в UI

1. **По умолчанию выбран женский пол**
   - Показываются женские подсказки

2. **Пользователь переключает на мужской**
   - `setState(() => _selectedGender = _Gender.male)`
   - UI перестраивается
   - Методы `_getXxxHint()` возвращают мужские примеры
   - Подсказки обновляются мгновенно

3. **Переключение обратно**
   - Снова показываются женские подсказки
   - Всё работает плавно без задержек

### Технические детали

```dart
// При изменении пола
onTap: () => setState(() => _selectedGender = _Gender.male)

// В методе build
hint: _getStyleHint()  // ← вызывается каждый раз при rebuild

// В методе подсказки
String _getStyleHint() {
  return _selectedGender == _Gender.female
      ? 'женские примеры'
      : 'мужские примеры';
}
```

## 📱 Пример использования

### Сценарий 1: Девушка создаёт романтичную фотосессию

1. Открывает экран → автоматически "Женский" пол
2. Видит подсказки:
   - Место: "Уютное кафе в Париже..."
   - Образ: "Вечернее платье..."
3. Вдохновляется и вводит:
   - Место: "Цветущий сад в Италии"
   - Образ: "Лёгкое белое платье макси"
4. Генерирует промпт и создаёт фотосессию

### Сценарий 2: Парень создаёт деловую фотосессию

1. Открывает экран → переключает на "Мужской"
2. Видит обновлённые подсказки:
   - Место: "Крыша небоскрёба..."
   - Образ: "Деловой костюм-тройка..."
3. Вдохновляется и вводит:
   - Место: "Офис с панорамными окнами"
   - Образ: "Тёмно-синий костюм с галстуком"
4. Генерирует промпт и создаёт фотосессию

### Сценарий 3: Экспериментирование

1. Начинает с женского пола, читает подсказки
2. Переключает на мужской - видит другие идеи
3. Выбирает понравившийся стиль
4. Комбинирует идеи из обеих категорий

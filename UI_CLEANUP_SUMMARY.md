# Очистка UI экрана создания фотосессии

## ✅ Что сделано

### 1. Удалён переключатель темы

**Было:**
```dart
appBar: AppBar(
  title: const Text('Создать свою фотосессию'),
  actions: [
    IconButton(
      icon: Icon(isDark ? Icons.light_mode_outlined : Icons.dark_mode_outlined),
      onPressed: () => ref.read(themeModeProvider.notifier).toggle(),
      tooltip: isDark ? 'Светлая тема' : 'Тёмная тема',
    ),
  ],
)
```

**Стало:**
```dart
appBar: AppBar(
  title: const Text(
    'Создать свою фотосессию',
    style: TextStyle(
      fontWeight: FontWeight.w600,
      fontSize: 18,
    ),
  ),
)
```

### 2. Оптимизирован размер заголовка

- Добавлен явный `fontSize: 18` для заголовка
- Это гарантирует что текст "Создать свою фотосессию" полностью помещается на экране
- На маленьких экранах текст не будет обрезаться

### 3. Удалены неиспользуемые элементы

- Удалён импорт `theme_service.dart` (больше не нужен)
- Удалена неиспользуемая переменная `isDark` из метода `build()`
- Код стал чище и легче

## Преимущества

✅ **Чище UI** - убрана лишняя кнопка из AppBar  
✅ **Больше места** - весь фокус на заголовке и вкладках  
✅ **Лучше читаемость** - заголовок точно помещается на экране  
✅ **Чище код** - удалены неиспользуемые импорты и переменные

## Где можно переключить тему?

Переключатель темы остался на других экранах приложения (главный экран, настройки и т.д.). Этот экран специально упрощён для лучшего UX.

# Инструкция по тестированию Face Swap

## Что улучшено

### 1. Строгое сохранение внешности
Добавлены параметры для максимально точного копирования лица:

```dart
'input': {
  'target_image': targetImageUrl,       // Пресет с фотосессии
  'swap_image': swapImageUrl,           // Ваше фото
  'face_restore': true,                 // Восстановление деталей лица
  'upscale': 1,                         // Масштабирование
  'blend_ratio': 1.0,                   // 100% замены лица
},
'extra': {
  'prompt': 'СТРОГО сохранить внешность 1:1 — лицо, черты, пропорции...',
  'preserve_identity': true,            // Сохранение идентичности
  'face_enhancement': true,             // Улучшение качества
}
```

### 2. Подробное логирование
Теперь в логах будут видны все этапы:
- Создание задачи face-swap
- URL целевого и подставляемого изображения
- Статус каждого опроса API
- Финальный результат или ошибка

## Как протестировать

### Шаг 1: Hot Restart
В терминале где запущен `flutter run` нажми **R** (заглавная)

### Шаг 2: Откройте пресет
1. На главном экране выберите любой пресет из сетки
2. Нажмите **"Добавить своё фото"**

### Шаг 3: Выберите фото
Выберите фото лица из галереи. Лучше всего:
- Чёткое фото лица анфас
- Хорошее освещение
- Лицо занимает большую часть кадра
- Без очков и масок

### Шаг 4: Ожидание
Появится индикатор "Подставляем ваше лицо…"

Процесс занимает 10-30 секунд:
1. Загрузка вашего фото на сервер PiAPI
2. Создание задачи face-swap
3. Обработка (замена лица)
4. Получение результата

### Шаг 5: Проверка логов
В терминале должны появиться логи:

```
Faceswap: создание задачи target=https://... swap=https://...
Faceswap: ответ создания 200: {"data":{"task_id":"xxx"...}}
Faceswap: начинаем опрос задачи xxx
Faceswap: опрос #1, статус 200
Faceswap: статус задачи=processing, url=null
Faceswap: опрос #2, статус 200
Faceswap: статус задачи=completed, url=https://...
Faceswap: задача завершена (completed=true, failed=false)
```

### Шаг 6: Результат
После обработки отобразится фото с вашим лицом на фоне пресета.

## Если не работает

### Проблема: "Не удалось загрузить фото"
**Решение:** Проверь `PIAPI_UPLOAD_URL` в `.env` (строка 43):
```
PIAPI_UPLOAD_URL=https://upload.theapi.app/api/ephemeral_resource
```

### Проблема: "Не удалось применить смену лица"
**Решение:** 
1. Проверь `PIAPI_API_KEY` в `.env` (строка 29)
2. Проверь `PIAPI_TASK_URL` в `.env` (строка 31)
3. Посмотри логи в терминале — там будет точная ошибка

### Проблема: Логи показывают "Syntax error"
**Решение:** API PiAPI может не поддерживать параметры `extra`. В этом случае нужно убрать секцию `extra` из payload.

### Проблема: Результат не похож на ваше лицо
**Причины:**
1. Фото плохого качества (размытое, темное)
2. Лицо повернуто в профиль
3. На фото несколько лиц - API не знает какое использовать
4. Очки, маска, борода сильно искажают результат

**Решение:** Используйте качественное фото лица анфас с хорошим освещением.

## Технические детали

### Face Swap параметры
- `face_restore: true` — восстанавливает детали лица после замены
- `blend_ratio: 1.0` — 100% замена (0.0 = целевое фото, 1.0 = ваше лицо)
- `preserve_identity: true` — максимальное сохранение ваших черт

### Таймауты
- Создание задачи: 30 сек
- Опрос статуса: каждые 2 сек
- Максимальное время обработки: 2 минуты

### API endpoint
```
POST https://api.piapi.ai/api/v1/task
GET  https://api.piapi.ai/api/v1/task/{taskId}
```

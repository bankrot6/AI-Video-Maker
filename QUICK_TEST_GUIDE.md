## ✅ Чек-лист тестирования

### 1️⃣ Тест динамических подсказок (30 сек)

1. Откройте экран **"Создать свою фотосессию"**
2. По умолчанию выбран **"Женский"** пол
   - Проверьте поле "Образ" → должно быть: *"Вечернее платье, лёгкий летний сарафан..."*
   - Проверьте поле "Детали" → должно быть: *"Букет пионов, изящные украшения..."*

3. Переключите на **"Мужской"** пол
   - Подсказки должны измениться мгновенно
   - "Образ" → *"Деловой костюм-тройка, casual кожаная куртка..."*
   - "Детали" → *"Стильные часы, борода с усами..."*

4. Переключите обратно на **"Женский"**
   - Подсказки вернутся к женским вариантам

✅ **Ожидаемый результат:** Подсказки меняются моментально при каждом переключении

---

### 2️⃣ Тест клавиатуры (20 сек)

1. На экране "Создать свою фотосессию"
2. Нажмите на любое текстовое поле (Место, Образ, Настроение, Детали)
3. Клавиатура откроется
4. Попробуйте прокрутить экран вверх/вниз

✅ **Ожидаемый результат:**
- Нет ошибок "RenderFlex overflowed" в логах
- Контент прокручивается плавно
- Все поля доступны

---

### 3️⃣ Тест генерации через Google API (2-3 мин)

1. Заполните поля:
   - Место: "Парижское кафе"
   - Образ: "Элегантное платье"
   
2. Нажмите **"Сгенерировать промпт"** → дождитесь результата

3. Перейдите на вкладку **"Фото"**

4. Загрузите своё фото

5. Нажмите **"Создать фотосессию"**

6. **Смотрите логи в консоли:**
   ```
   🔀 ROUTER: доступность Google=true, Piapi=true
   🔀 ROUTER: пробуем Google API для generateWithFace
   🟢 GOOGLE_DIRECT: генерация с лицом
   🟢 GOOGLE_DIRECT: изображение сохранено ...
   🔀 ROUTER: Google API успешно
   ```

✅ **Ожидаемый результат:**
- В логах видно `🟢 GOOGLE_DIRECT` (используется Google API)
- Фотосессия создаётся за 1-2 минуты
- Результат сохраняется в разделе "Мои"

---

### 4️⃣ Тест fallback на PiAPI (опционально)

Этот тест проверяет что fallback работает при ошибке Google API.

1. **Временно** отредактируйте `.env`:
   ```env
   NANO_BANANA_API_KEY=wrong_key
   ```

2. Сделайте hot restart: `R`

3. Попробуйте создать фотосессию (шаги из теста 3)

4. **Смотрите логи:**
   ```
   🔀 ROUTER: доступность Google=false, Piapi=true
   🔀 ROUTER: переключаемся на Piapi для generateWithFace
   🟣 PIAPI: задача создана, ID=...
   ```

5. **Верните правильный ключ обратно:**
   ```env
   NANO_BANANA_API_KEY=AQ.Ab8RN...
   ```

6. Сделайте hot restart: `R`

✅ **Ожидаемый результат:**
- При неправильном Google API ключе используется PiAPI
- При правильном ключе снова используется Google API

## 🐛 Что делать при проблемах

### Проблема: Подсказки не меняются

**Решение:**
1. Сделайте hot restart (R)
2. Убедитесь что код сохранён
3. Проверьте что методы `_getXxxHint()` присутствуют в файле

---

### Проблема: Ошибка overflow при клавиатуре

**Решение:**
1. Убедитесь что сделали hot restart (R) после изменений
2. Проверьте что `resizeToAvoidBottomInset: true` в Scaffold
3. Проверьте что `_buildInputTab` использует `SingleChildScrollView`

---

### Проблема: Генерация не работает

**Проверьте логи:**

Если видите:
```
🔀 ROUTER: доступность Google=false, Piapi=false
```

**Действия:**
1. Откройте `.env` файл
2. Убедитесь что есть хотя бы один из ключей:
   - `NANO_BANANA_API_KEY=...` (Google)
   - `PIAPI_API_KEY=...` (PiAPI)
3. Сделайте hot restart: `R`

---

### Проблема: Google API не работает, только PiAPI

Если постоянно видите `🟣 PIAPI` вместо `🟢 GOOGLE_DIRECT`:

**Действия:**
1. Проверьте `.env`:
   ```env
   NANO_BANANA_API_KEY=AQ.Ab8RN...  # Должен быть заполнен
   NANO_BANANA_PROJECT_ID=enhanced-mote-485505-a8
   NANO_BANANA_MODEL=gemini-2.5-flash-image
   ```
2. Убедитесь что API ключ активен в Google Cloud Console
3. Проверьте квоты Vertex AI в консоли
4. Сделайте hot restart: `R`

# Инструкция по развертыванию системы вознаграждений

## Быстрый старт

### 1. Обновить зависимости Flutter
```bash
flutter pub get
```

### 2. Развернуть Firestore конфигурацию
```bash
# Применить правила безопасности
firebase deploy --only firestore:rules

# Применить индексы
firebase deploy --only firestore:indexes
```

### 3. Развернуть Cloud Functions
```bash
cd functions
npm install
cd ..
firebase deploy --only functions:processPresetRewards
```

### 4. Пересобрать приложение
```bash
# Android
flutter build apk --release

# iOS
flutter build ios --release
```

## Проверка работы

### 1. Создать тестовый пресет
1. Запустить приложение
2. Создать новый пресет
3. Сделать его публичным
4. Проверить, что появилось сообщение о заработке

### 2. Проверить Cloud Function
```bash
# Посмотреть логи
firebase functions:log --only processPresetRewards

# Ожидаемый лог при добавлении лайка:
# ✅ Reward: preset preset_123 earned 1 credits (4 likes, owner: device_abc)
```

### 3. Проверить Firestore
В Firebase Console → Firestore → должна появиться коллекция `preset_earnings`

### 4. Проверить UI
1. Поставить 3+ лайков на тестовый публичный пресет
2. Перезапустить приложение
3. Должен появиться SnackBar: "🎉 Вы получили X кредитов за лайки!"
4. В showcase screen справа должен появиться зеленый бадж "Заработано: +X"

## Возможные проблемы

### Cloud Function не срабатывает
**Проблема**: Лайки добавляются, но кредиты не начисляются
**Решение**: 
- Проверить логи: `firebase functions:log`
- Убедиться, что пресет публичный и имеет ownerId
- Проверить, что количество лайков >= 3

### Индексы не созданы
**Проблема**: Ошибка при запросе к Firestore
**Решение**: 
- Применить индексы: `firebase deploy --only firestore:indexes`
- Подождать несколько минут для создания индексов
- Можно создать индексы вручную через Firebase Console

### Бадж не отображается
**Проблема**: Зеленый бадж "Заработано" не виден
**Решение**:
- Убедиться, что есть заработанные кредиты (проверить Firestore)
- Вызвать синхронизацию вручную
- Проверить логи: `PresetRewardService().syncEarnedCredits()`

## Мониторинг

### Ежедневные проверки
```bash
# Логи Cloud Functions за последние 24 часа
firebase functions:log --since 24h

# Статистика в Firestore Console
# Коллекция: preset_earnings
# Сортировка: creditsEarned (descending)
```

### Метрики для отслеживания
- Количество публичных пресетов
- Среднее количество лайков на пресет
- Количество пользователей с заработком > 0
- Топ-10 пресетов по заработку

## Настройка экономики

Все параметры находятся в `lib/models/preset_earnings.dart`:

```dart
static const int creditsPerLike = 1;        // Кредитов за лайк
static const int minLikesForReward = 3;     // Минимум лайков
static const int maxCreditsPerPreset = 50;  // Максимум кредитов
```

После изменения параметров:
1. Обновить константы в Cloud Function (`functions/index.js`)
2. Пересобрать приложение
3. Задеплоить Cloud Function
